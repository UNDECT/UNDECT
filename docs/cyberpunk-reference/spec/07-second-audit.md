# 07. 2차 검토에서 찾은 빠진 요소

`01`~`06`을 레퍼런스의 플레이 흐름(접속 → 외형 → 조작 익히기 → 거리 → 전투 → 상점 → 시술 → 임무 → 쓰러짐 → 다시 시작)대로 한 번 더 따라가며 대조했다. 아래는 그때 빠져 있던 요소다. `01`~`06`과 같은 효력이고, 표 읽는 법은 `00-index.md`를 본다.

가장 큰 누락은 다섯 가지다.
1. **다른 사람 눈에 보이는 내 모습(3인칭 표현)**: 레퍼런스는 혼자 하는 게임이라 없지만, 이 게임은 멀티플레이라 반드시 필요하다.
2. **입력 장치별 조작**: 모바일 터치, 패드 진동, 조준 보정.
3. **처음 접속한 사람의 흐름**: 외형 만들기부터 첫 전투까지.
4. **맵 사이 이동 구조와 사냥터 규칙**: 허브와 모험 맵을 기술적으로 어떻게 잇는가.
5. **피해 계산 규칙과 해킹 덱 구조**: 화면에는 안 보이지만 손맛을 정하는 규칙.

## A. 3인칭 표현 (`TPS`) — 다른 플레이어와 그림자·거울에 보이는 내 캐릭터

## K. 이 스펙이 다루지 않는 것 (빠뜨린 게 아니라 범위 밖)
- **이야기와 임무 내용**(주 이야기, 인물, 대사 대본): 레퍼런스 것은 가져올 수 없고 자체 창작이 필요하다. 틀(QST)만 있다.
- **밸런스 숫자**(피해량, 가격, 경험치 곡선): 구조만 정했다. 숫자는 플레이하며 맞춘다.
- **수익화**(게임패스, 유료 아이템): 요청이 없어서 넣지 않았다.
- **운영**(업데이트 공지, 이벤트, 신고): 넣지 않았다.
