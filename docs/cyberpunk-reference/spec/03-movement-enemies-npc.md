## E. 세력 (`FAC`) — 전부 자체 제작
레퍼런스에는 겉모습과 싸우는 방식이 뚜렷이 다른 세력이 여럿 있다. 같은 구조로 **자체 세력 6~8개**를 만든다. 이름·상징·색은 시안을 내고 사용자가 고른다.

| ID | 원형 | 겉모습 | 싸우는 방식 | 영역 분위기 |
|---|---|---|---|---|
| FAC-01 | 과잉 개조 갱 | 얼굴을 기계로 바꾸고 붉은 불빛, 중장갑 | 중화기, 정면 돌파 | 공업 지대, 붉은 조명 |
| FAC-02 | 전통과 첨단이 섞인 조직 | 문신, 정장, 긴 칼 | 칼과 권총, 빠른 근접 | 유흥가, 네온 |
| FAC-03 | 근육 숭배 갱 | 거대한 덩치, 동물 상징 | 맨손과 둔기, 버티기 | 체육관, 시장 |
| FAC-04 | 거리 수호 갱 | 화려한 장식, 금색, 낡은 차 | 권총과 리볼버, 자기 구역 방어 | 주택가, 벽화 |
| FAC-05 | 해커 집단 | 얼굴 가득 접속 단자, 어두운 옷 | 해킹과 드론 | 버려진 건물, 서버 방 |
| FAC-06 | 장기 약탈자 | 지저분한 수술복, 조잡한 개조 | 매복 | 폐건물, 냉동고 |
| FAC-07 | 황무지 유목민 | 먼지 묻은 가죽옷, 개조 차량 | 차량전, 저격 | 도시 외곽, 야영지 |
| FAC-08 | 기업 경비 | 깔끔한 전투복, 최신 장비 | 조직적 엄폐, 방패, 드론 | 기업 구역, 흰 조명 |
| FAC-09 | 경찰과 특수 진압대 | 제복, 방패 / 최정예 중장갑 | 수배 단계별 대응 | 도시 전역 |

- 세력마다: 로고, 색 2개, 옷 스타일, 그래피티 무늬, 차량 도색, 대사 말투, 영역 표시를 만든다(P2, 승인 후).
- 영역에 들어가면 화면에 세력 이름이 뜨고, 벽화와 깃발로 누구 땅인지 알 수 있다.

- 재고는 시간이 지나면 바뀐다. 상인마다 돈 한도가 있다.
