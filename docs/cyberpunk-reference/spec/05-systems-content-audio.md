# 05. 성장·아이템 · 콘텐츠 구조 · 차량 · 사운드 · 연출 · 멀티플레이 · 제외 목록

표 읽는 법과 규칙은 `00-index.md`를 본다. 장기 방향은 "메이플식 성장 구조 + 사이버펑크"이므로, 성장 구조는 레퍼런스를 그대로 따르지 않고 **자체 설계가 우선**이다. 여기서는 레퍼런스에 있는 요소를 빠짐없이 적고, 어떻게 받아들일지 표시한다.

## G. 멀티플레이 적용 (`MP`) — 레퍼런스는 혼자 하는 게임이다. 여럿이 할 때 처리 원칙
| ID | 문제 | 처리 |
|---|---|---|
| MP-01 | 시간 감속 | 서버 버블(적)과 내 화면 전용(비·파티클·소리)을 나눈다. 다른 사람에게는 잔상이 보인다 |
| MP-02 | 화면 효과 | 전부 내 화면에만. 남의 능력은 3인칭 연출(CW-08)로 본다 |
| MP-03 | 전리품 | 사람마다 따로 떨어지고 따로 줍는다 |
| MP-04 | 대화·상점 | 내 화면에만 뜬다. 대화 중인 NPC는 다른 사람에게 "대화 중" 동작만 보인다. NPC는 여러 사람과 동시에 대화할 수 있다 |
| MP-05 | 시술 의자 | 의자는 하나지만 시술 장면은 내 화면에서만 진행한다. 다른 사람 눈에는 내가 잠깐 안 보이거나 앉은 모습만 보인다. 줄 서기 없음 |
| MP-06 | 개인 공간 | 집은 사람마다 따로 보인다(같은 문, 다른 내부) |
| MP-07 | 임무 진행 | 개인 진행과 파티 공유를 구분한다. 파티장이 진행하면 파티원도 넘어간다 |
| MP-08 | 군중·교통 | 내 화면에서만 돌아간다(서버 부담 없음). 총성 반응 같은 큰 사건만 서버가 알린다 |
| MP-09 | 적 난이도 | 사람 수에 따라 적 체력과 수를 조절한다 |
| MP-10 | 해킹·은신 | 한 명이 들키면 파티 전체가 전투 상태. 해킹 대기열은 대상 기준으로 공유 |
| MP-11 | 부정 방지 | 피해, 탄 퍼짐, 쿨다운, 돈, 아이템은 서버가 판정한다 |
| MP-12 | 저장 | 진행, 장비, 진화, 외형, 설정을 DataStore에 저장하고 버전을 관리한다 |

## H. 제외·순화 목록 (`CUT`) — 임의로 빼지 말고 이대로 처리
레퍼런스는 성인용 게임이다. 로블록스 정책과 이 게임의 키즈 설정 때문에 아래는 그대로 넣을 수 없다. **빠뜨린 게 아니라 결정한 것**이다.

| ID | 레퍼런스 요소 | 처리 | 대체 |
|---|---|---|---|
| CUT-01 | 사실적인 피, 절단, 시체 | 넣지 않음 | 랙돌 후 디지털 분해, 크롬 부품 이탈, 데이터 입자(Phase 0 결정) |
| CUT-02 | 성적 내용, 노출, 성인 업소, 연애 | 넣지 않음 | 유흥가는 클럽·공연장·오락실 분위기로. 광고는 선정적이지 않게 |
| CUT-03 | 욕설, 비속어 | 넣지 않음 | 거친 말투는 유지하되 자체 은어를 만든다(세계관 속 속어) |
| CUT-04 | 마약, 약물 | 넣지 않음 | "강화 칩", "과부하 프로그램" 같은 전자적 대체물 |
| CUT-05 | 술, 담배 | 넣지 않음 | 합성 음료, 에너지 드링크, 전자 향 스틱 없이 음료만. 술집은 "음료 바" |
| CUT-06 | 도박 | 넣지 않음 | 오락실 게임(돈 걸기 없음) |
