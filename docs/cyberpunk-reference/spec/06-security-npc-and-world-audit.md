# 1부. 보안 NPC (`SEC`)

지금 보안 NPC(보안 로봇 등)는 Blender 작업 전의 옛 버전이다. C2에서 만든 사실적인 행인 옆에 서면 혼자 다른 게임처럼 보인다. **허브 작업(C7) 바로 다음에 `C7b` 단계로 재제작한다.** 새 적 종류는 승인 전이므로, **지금 있는 보안 NPC를 같은 역할 그대로 새로 만드는 것**이 범위다. 기존 AI, 판정, 테스트는 유지하고 겉모습·동작·연출·소리를 바꾼다.

## A. 종류 (지금 있는 것만 재제작, 나머지는 구조만)
| ID | 종류 | 역할 | 범위 |
|---|---|---|---|
| SEC-01 | 순찰 보안 로봇(인간형) | 정해진 길을 돌며 살핀다 | **재제작** |
| SEC-02 | 고정 경비 로봇 | 출입구와 검문 지점을 지킨다 | 지금 있으면 재제작, 없으면 SEC-01의 자세 변형 |

| SEC-04 | 보안 포탑·카메라 | 천장과 벽에 붙어 감시한다 | 지금 있으면 재제작, 없으면 구조만 |

## F. C7b 진행 순서
1. 지금 있는 보안 NPC 목록(종류, 쓰는 코드, 판정 부위, 배치 위치)을 정리한다.
2. 자체 보안 회사 설정과 외형 시안 2~3개를 Blender 렌더로 보여 주고 **멈춘다**.
3. 승인된 시안으로 SEC-01을 끝까지 만든다(모델, LOD, 동작, 연출, 소리). 기존 판정 부위와 AI에 연결한다. Lune 테스트 통과.
4. 허브에 세워 낮·밤 사진, 행인과 나란히 선 사진, 전투 영상용 연속 사진을 찍어 보고한다.
5. 나머지 종류(있는 것만)를 같은 방식으로 바꾼다.

## J. 맵에 심어야 하는 보이지 않는 정보

## K. 검토 결과 요약
- `04` 1부에 없던 것 중 가장 큰 것은 **위에서 본 도시(WLD-110)**, **구역 등급(WLD-120)**, **맵에 심는 정보(WLD-150~159)**, **대형 랜드마크(WLD-135)**다.
- 간판 문제의 재발을 막으려면 WLD-50의 광고도 `SignageRules` 검사를 거치게 한다.
- 개발 세션은 커버리지 감사 때 이 파일의 `WLD-110` 이후 항목도 같이 대조한다.
