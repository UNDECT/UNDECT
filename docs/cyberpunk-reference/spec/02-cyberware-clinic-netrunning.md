# 02. 시술소 · 시술의 · 사이버웨어 · 넷러닝

표 읽는 법과 규칙은 `00-index.md`를 본다. 이름은 전부 자체 제작이다. 이 문서에서 "시술의"는 사이버웨어를 설치해 주는 의사 NPC를 가리킨다.

## A. 시술소 공간 (`CLN`)

시술소는 "메뉴가 열리는 지점"이 아니라 **들어가 보고 싶은 장소**여야 한다.

1인칭 시점을 유지한 채 진행한다. 화면이 툭 끊겨 메뉴로 넘어가면 안 된다.
