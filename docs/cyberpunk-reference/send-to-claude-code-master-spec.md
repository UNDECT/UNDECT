## 지시
1. 지금 하는 **C2는 그대로 끝낸다.** 이 메시지 때문에 C2를 바꾸지 않는다.
2. 이 파일을 `docs/spec/` 아래에 저장한다(아래 `=====` 구분선마다 파일 하나다. 파일 이름은 구분선에 적혀 있다).
3. C2가 끝나면 `00-index.md` 4번의 **커버리지 감사**부터 한다: 모든 ID를 실제 코드와 대조해 `docs/spec/coverage.md`를 만들고, 스펙에서 빠진 요소를 찾으면 `docs/spec/missing.md`에 적는다. P0/P1/P2별 개수를 보고하고 멈춘다.
4. 그 뒤 `00-index.md` 6번 단계 표대로 진행한다. 단계 순서: C3~C7 허브 → **C7b 보안 NPC 재제작** → C8~C9 UI → C10 팔·총 → C11 사이버웨어·시술소 → C12 플레이어 → C13 차량 → C14~ 모험 맵.
5. 앞서 받은 문서(C3 절차, UI·맵, 캐릭터, 그래픽, 엔진 한계 돌파)는 "순서와 방법"으로 계속 유효하다. 요소 목록이 서로 다르면 이 스펙이 우선이다.

모든 요소는 한 줄이다.

| 열 | 뜻 |

## 3. 절대 규칙 (기존 규칙 전부 유지)
- 답은 한국어. `cyber-3v3.rbxl` 저장 금지. `rojo build -o cyber-rpg.rbxl` 금지. computer-use 금지. Studio 확인은 직접 한다.
- 기능 브랜치에서만 커밋하고, 커밋 메시지 끝에는 프로젝트에서 쓰던 Co-Authored-By 줄을 그대로 붙인다. Lune 테스트 전부 통과.
- **진행 중인 C2는 건드리지 않는다.**
- **자체 디자인 원칙**: 레퍼런스의 메커니즘·연출 원리·기능 구조는 그대로 가져온다. 하지만 **고유명사(인물·기업·갱·지역·무기·능력 이름), 로고, 캐릭터 외모, UI 색 조합과 레이아웃 그대로 따라 하기, 지도·랜드마크, 음악·음성**은 가져오지 않고 전부 자체 제작한다. 이 스펙도 그래서 고유명사 없이 "기능"으로만 적었다. 자체 이름은 개발 세션이 시안 2~3개를 내고 사용자가 고른다.
- 툴박스 스크립트 금지(차량 섀시 포함, 직접 만든다). 에셋은 자체 제작, CC0, 라이선스 확인된 크리에이터 스토어 에셋만 쓴다.
- 키즈 설정(`GameConfig.Kids`)과 Phase 0 처치 표현 결정을 따른다. 로블록스 정책상 넣을 수 없는 요소는 `05`의 **제외·순화 목록(CUT)**에 대체안과 함께 적었다. 임의로 빼지 말고 그 목록대로 처리한다.

## 4. 개발 세션이 먼저 할 일 — 커버리지 감사
1. 6개 파일(`01`~`06`)의 **모든 ID**를 실제 코드와 대조해 `docs/spec/coverage.md`를 만든다.
   - 열: ID / 상태(✅ 있음, 🟡 일부, ❌ 없음, ⛔ 제외) / 근거 파일 / 부족한 점 / 배정 단계
2. 스펙에 없는데 코드에 이미 있는 기능(비행·벽타기·그래플·진화 시스템 등 자체 확장)은 "자체 확장" 섹션에 적는다. 지우지 않는다.
3. 스펙에서 **빠진 요소를 발견하면** `docs/spec/missing.md`에 적고 사용자에게 알린다. 레퍼런스에 대해 아는 것 중 이 스펙에 없는 것은 전부 적는다.
4. 감사 결과를 숫자로 보고한다(P0/P1/P2별 ✅🟡❌ 개수). 여기까지 하고 멈춘다. C2 진행 중이면 C2를 끝낸 뒤 한다.

## 5. 단계마다 지킬 것
- 단계를 시작할 때 그 단계에 배정된 ID 목록을 먼저 보여 준다.
- 한 요소는 **화면·소리·카메라·UI 4채널**을 다 채워야 ✅다. 소리 에셋이 없으면 SFX 레지스트리에 키만 등록하고 임시음을 매핑한다.
- 단계가 끝나면 `coverage.md`를 갱신하고, ✅로 바뀐 ID마다 증거(스크린샷·로그·측정값)를 붙인다.
- 스펙과 다르게 만들었으면 이유를 적는다.

# 02. 시술소 · 시술의 · 사이버웨어 · 넷러닝

## L. UI 공통 기준
- 모든 화면: 열고 닫을 때 글리치 전환, 배경 흐림, 소리. 100ms 안에 열린다.
- PC, 패드, 모바일에서 모두 조작된다. 모바일은 버튼 크기와 배치를 따로 잡는다.
- 한국어 기준으로 줄바꿈과 잘림을 확인한다.
- 흔들림·번쩍임 줄이기 설정을 모든 화면 효과가 따른다.

## H. 제외·순화 목록 (`CUT`) — 임의로 빼지 말고 이대로 처리
레퍼런스는 성인용 게임이다. 로블록스 정책과 이 게임의 키즈 설정 때문에 아래는 그대로 넣을 수 없다. **빠뜨린 게 아니라 결정한 것**이다.

| ID | 레퍼런스 요소 | 처리 | 대체 |
|---|---|---|---|
| CUT-01 | 사실적인 피, 절단, 시체 | 넣지 않음 | 랙돌 후 디지털 분해, 크롬 부품 이탈, 데이터 입자(Phase 0 결정) |
| CUT-02 | 성적 내용, 노출, 성인 업소, 연애 | 넣지 않음 | 유흥가는 클럽·공연장·오락실 분위기로. 광고는 선정적이지 않게 |
| CUT-03 | 욕설, 비속어 | 넣지 않음 | 거친 말투는 유지하되 자체 은어를 만든다(세계관 속 속어) |
| CUT-04 | 마약, 약물 | 넣지 않음 | "강화 칩", "과부하 프로그램" 같은 전자적 대체물 |
| CUT-05 | 술, 담배 | 넣지 않음 | 합성 음료, 에너지 드링크, 전자 향 스틱 없이 음료만. 술집은 "음료 바" |
| CUT-06 | 도박 | 넣지 않음 | 오락실 게임(돈 걸기 없음) |
| CUT-07 | 실존 종교·정치·실존 인물과 브랜드 | 넣지 않음 | 전부 가상 |

등급을 올리면(Moderate, Restricted) 일부는 풀 수 있다. 하지만 접근할 수 있는 이용자 연령이 올라가므로 사용자 결정 사항이다.

# 06. 보안 NPC 재제작 · 배경·맵 검토에서 찾은 빠진 요소

# 1부. 보안 NPC (`SEC`)

지금 보안 NPC(보안 로봇 등)는 Blender 작업 전의 옛 버전이다. C2에서 만든 사실적인 행인 옆에 서면 혼자 다른 게임처럼 보인다. **허브 작업(C7) 바로 다음에 `C7b` 단계로 재제작한다.** 새 적 종류는 승인 전이므로, **지금 있는 보안 NPC를 같은 역할 그대로 새로 만드는 것**이 범위다. 기존 AI, 판정, 테스트는 유지하고 겉모습·동작·연출·소리를 바꾼다.
