# 사이버웨어 팔 시범 모델

코드만으로 만든 사이버웨어 팔이다(자체 디자인, 손으로 모델링한 부분 없음). `make_arm.py` 한 파일이 형상, 재질, 조명, 렌더, 내보내기를 다 한다.

| 파일 | 내용 |
|---|---|
| `make_arm.py` | 생성 스크립트. `python make_arm.py <출력폴더> [closed\|open\|all]` (`pip install bpy` 필요) |
| `arm_closed_34.png` | 닫힌 상태 |
| `arm_blade_34.png` | 등쪽 장갑이 양옆으로 열리고 칼날이 나온 상태 |
| `arm_closed_hand.png` | 손 확대 |
| `arm_closed_side.png` | 옆모습 |
| `cyber_arm_closed.glb` | 닫힌 상태 모델(절차 재질은 색만 들어감) |

## 구조
- 부품 약 180개가 따로 떨어진 오브젝트다: 인공 근육 심, 등쪽 장갑 문 4장, 옆·배쪽 장갑, 유압 피스톤, 팔꿈치 경첩, 주름 고무, 케이블, 손목 관절, 손바닥, 손가락 마디.
- 등쪽 장갑 문은 바깥 모서리를 축으로 56° 열린다. 칼날은 칼집에서 앞으로 나온다. 꺼내기 애니메이션에 그대로 쓸 수 있는 구조다.
- 삼각형 수는 약 5만 4천 개다.

## 게임에 넣으려면 남은 일
1. 절차 재질을 텍스처(Color/Normal/Roughness/Metalness + 발광 마스크)로 굽기
2. 부품을 움직이는 단위로 합치고 뼈 달기(문 2개, 칼날, 손가락 15마디, 손목, 팔꿈치)
3. 메시당 삼각형 2만 개 이하로 나누고 LOD 3단 만들기
4. 1인칭 화면에서 보이는 각도(팔 안쪽, 손바닥 쪽) 디테일 보강
