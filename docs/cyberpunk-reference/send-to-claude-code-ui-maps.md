## 0. 전제
- 지금 하는 **C2는 그대로 끝낸다.** 이 메시지는 C2 이후 계획만 바꾼다.
- 목표: 레퍼런스 사이버펑크 게임을 플레이할 때와 **같은 체감 품질**을 낸다. **인터페이스와 맵까지 전부** 해당한다.
- 단, **그 게임의 UI 디자인(색 조합, 레이아웃 그대로 따라 하기, 폰트, 아이콘, 로고)과 도시 지도·랜드마크는 복제하지 않는다.** 장르 공통 원리와 기능 구조는 가져오고, 모양과 이름은 자체 디자인으로 만든다. 이건 프로젝트 규칙(다른 게임의 이름·에셋 금지)이기도 하다.
- 기존 규칙 그대로: 한국어, `cyber-3v3.rbxl` 저장 금지, `rojo build -o cyber-rpg.rbxl` 금지, computer-use 금지, 기능 브랜치 커밋(+ `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`), Lune 테스트 전부 통과, Studio 확인은 네가 직접.

## 2. C8 — UI 디자인 시스템 + HUD

### 2-1. 레퍼런스 UI가 "사이버펑크처럼" 느껴지는 원리 (이걸 구현)
1. **사이버 안구 화면이라는 설정**: UI가 눈 속 디스플레이처럼 보인다. 켜질 때 부팅되고, 맞으면 지지직거리고, 해킹당하면 깨진다.
2. **각진 패널, 얇은 선, 모서리 사선 컷**, 작은 보조 숫자와 장식 텍스트(좌표, 코드, 바코드풍).
3. **2색 + 경고색** 체계: 기본색 하나와 보조색 하나로 거의 모든 것을 그리고, 위험만 경고색으로 한다. 자체 색은 Phase 0에서 고른 `UiTheme`을 쓴다(레퍼런스의 빨강+시안 조합은 쓰지 않는다).
4. **끊임없는 미세 움직임**: 숫자 롤링, 선이 그려지며 등장, 깜빡이는 커서, 스캔라인.
5. **정보 밀도는 높지만 위계가 분명하다**: 큰 숫자 하나 + 작은 보조 정보 여러 개.
6. **글리치 전환**: 화면이 바뀔 때 RGB 어긋남, 가로 찢김, 0.1~0.2초 노이즈.

### 2-2. 할 일
- `UiTheme` 확장: 색 토큰, 폰트 위계(로블록스 내장 폰트 중에서 고름: 제목, 본문, 숫자 모노스페이스), 패널·버튼·탭·슬라이더·툴팁·진행 바·목록 컴포넌트, 등장/퇴장/글리치 애니메이션 함수.
- **UI 견본 화면**(Studio 전용): 모든 컴포넌트를 한 화면에 늘어놓아 스크린샷으로 확인한다.
- HUD 전면 교체(기존 갭 표 Phase 4 항목 전부): 체력 지연 바, 상태 아이콘, RAM 칸, 스태미나, 사이버웨어 쿨다운, 탄약, 원형 미니맵과 목표, 동적 조준선, 히트 마커 3종, 데미지 숫자 속성 색, 피격 방향, 화면 밖 적, 적 머리 위 UI, 큰 알림.
- 스캐너 화면, 해킹 목록, 적 해킹 경고 바, 침투 미니게임을 같은 디자인 언어로 맞춘다.
- 둥근 키즈 패널은 전부 없앤다.

## 3. C9 — 메뉴 화면 전체 + Blender 3D UI 요소

### 3-1. 만들 화면
| 화면 | 핵심 |
|---|---|
| 메인 메뉴 | 3D 도시 배경(허브 실제 장면 + 천천히 움직이는 카메라), 글리치 로고(자체), 메뉴 등장 애니메이션 |
| 일시정지·설정 | 그래픽 품질, 조작, 소리, 접근성(자막 크기, 흔들림 줄이기) |
| 인벤토리 | **3D 캐릭터 미리보기**(ViewportFrame + Blender 캐릭터, 회전), 장비 슬롯, 등급 색, 비교 툴팁(증가 초록/감소 빨강) |
| 시술소(사이버웨어) | **몸 홀로그램**(Blender 몸 메시를 홀로그램 재질로, 부위 클릭하면 확대), 슬롯, 진화 단계·적응도·A/B 갈림길 |
| 퍼크·스킬 트리 | 노드가 선으로 연결되고 해금하면 빛이 흘러 들어감 |
| 지도 | **홀로그램 3D 도시 지도**(허브를 단순화한 프록시를 ViewportFrame에 띄움, 구역별 색, 회전·확대), 아이콘, 경로 |
| 퀘스트·기록 | 목록 + 상세, 진행 상태 |
| 휴대폰·메시지 | 화면 구석 팝업, 대화형 메시지 목록 |
| 상점 | 상인별 테마(총포상, 해킹 상인, 시술소) |
| 대화 선택지 | 오른쪽 아래 목록, 주요 선택지 강조, 시간 제한 바 |
| 로딩 화면 | **자체 연출**(레퍼런스의 로딩 장면을 따라 하지 않음): 예를 들어 데이터 격자 위 도시 와이어프레임 + 진행 로그 |
| 사망·부활 | 신호 끊김 → 재부팅 연출 |
| 알림 | 레벨 업, 진화 가능, 아이템 획득, 구역 진입 |

### 3-2. Blender로 만드는 UI 재료
- **아이콘 일괄 렌더**: 총, 부착물, 사이버웨어, 아이템을 같은 조명과 각도로 정사영 렌더해 투명 PNG를 만든다. 자체 테두리 스타일을 입힌 뒤 업로드한다. 스크립트로 만들어 새 아이템이 생기면 다시 돌린다.
- **3D 미리보기 모델**: 인벤토리와 시술소용 캐릭터·사이버웨어 메시(C2와 같은 캐릭터 파이프라인 재사용, 저폴리 LOD 사용).
- **애니메이션 스프라이트 시트**: 부팅, 글리치, 로딩, 홀로그램 노이즈를 Blender에서 프레임 렌더해 시트로 만들고, ImageLabel의 `ImageRectOffset`으로 재생한다.
- **홀로그램 지도 프록시**: 허브 건물을 단순 덩어리로 내보내 지도용으로 쓴다(구역 색, 랜드마크만 디테일).
- 모든 렌더 스크립트는 `tools/blender/ui/`에 두고 `manifest.json`에 기록한다.

### 3-3. UI 공통 기준
- 모든 화면은 열 때와 닫을 때 글리치 전환이 있고, 배경 흐림(DOF)과 소리가 붙는다.
- PC(마우스·키보드), 패드, 모바일(터치)에서 모두 조작된다. 모바일은 글자 크기와 터치 영역을 따로 맞춘다.
- 화면 하나를 여는 데 100ms 이하. ViewportFrame은 화면이 열려 있을 때만 갱신한다.
- 텍스트는 한국어 기준으로 줄바꿈과 잘림을 확인한다.

## 4. C14~ — 모험 맵

### 4-1. 기획 먼저 (C14, 코드 최소)
- 메이플식 성장 구조(레벨대별 사냥터와 보스 구역)에 사이버펑크를 입힌다. **맵 이름과 장소는 전부 자체 제작**한다.
- 장르 대표 공간을 바탕으로 맵 후보 6~8개를 제안한다. 예시:
  - 메가빌딩 내부(주거층 복도, 실내 시장, 엘리베이터 코어)
  - 공업·항만 구역(컨테이너, 크레인, 공장)
  - 기업 본사 타워(수직 잠입, 보안 단계)
  - 도시 외곽 황무지(모래폭풍, 버려진 주유소, 거대 송전탑)
  - 지하(하수도, 폐지하철, 넷러너 은신처)
  - 사이버 공간(디지털 세계, 데이터 구조물)
- 맵마다 기획서 1장: 레벨대, 분위기 키워드, 색 팔레트(구역 스타일 4종 중 무엇), 랜드마크 1개, 동선 지도 시안, **진입 방법 3가지(정면 전투 / 은신 / 해킹)**, 적 배치 개념, 보스 공간. 적과 보스 설계는 아직 승인 전이니 "개념"만 적는다.
- 지도 시안은 위에서 본 그림(간단한 SVG나 Studio 회색 상자 스크린샷)으로 보여 준다.
- **여기서 멈추고 내가 맵 목록과 순서를 고른다.**

### 4-2. 맵 제작 (맵마다 반복)
1. **회색 상자**: 동선, 엄폐, 높이 차이, 3가지 진입로를 상자로 만들고 직접 걸어 보며 확인한다.
2. **모듈 키트**: 그 맵 스타일의 Blender 모듈(벽, 바닥, 문, 창, 배관, 소품)을 만든다. 허브 키트를 재사용할 수 있으면 재사용한다.
3. **아트 패스**: 허브와 같은 기준(건축 우선, 간판 계층, 빛과 어둠, 잡동사니, 반사, 대기)을 적용한다.
4. **연결**: 허브에서 이동하는 방법(지하철, 엘리베이터, 차량 연출)과 로딩 화면을 연결한다.
5. **검증**: 고정 촬영 지점 3곳 스크린샷, 측정표, fps, 동선 3가지가 모두 통과하는지 확인한다.

## 5. 시작
C2를 계속한다. C2가 끝나면 C3부터 순서대로 진행하고, C8 시작 전에 `UiTheme` 색 시안을 다시 보여 준다(Phase 0에서 이미 골랐으면 그대로 쓴다).
