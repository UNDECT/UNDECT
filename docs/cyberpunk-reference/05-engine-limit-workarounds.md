# 로블록스 엔진 한계 돌파 기법 — "안 된다던 것"을 구현하는 방법

> 앞 문서에서 "100% 똑같이는 불가능"이라고 적은 항목들을 다시 조사했다. 결론: **엔진 기능으로 바로 되는 건 아니지만, 우회 기법을 쓰면 체감상 거의 같게 만들 수 있다.**
> 조사 기준일: 2026-11-11. 로블록스 기능은 자주 바뀐다. Claude Code가 작업 전에 Creator Hub 문서로 최신 상태를 다시 확인한다.

## 0. 먼저 알아 둘 최신 엔진 기능 (이미 쓸 수 있음)

| 기능 | 상태 | 쓰는 곳 |
|---|---|---|
| **통합 조명(Unified Lighting)**: `Lighting.LightingStyle = Realistic` + `PrioritizeLightingQuality = true` (예전 Future) | 2025-07 정식 | 모든 장면의 기본. 예전 `Technology` 속성을 대체한다 |
| **발광 마스크(Emissive mask)**: SurfaceAppearance·MaterialVariant·TerrainDetail에 흑백 발광 마스크 + `EmissiveStrength`·`EmissiveTint` | 정식(발표됨) | 창문 불빛, 간판 글자, 광고, 네온 띠를 **텍스처 단위**로 빛나게 한다. Neon 파츠를 따로 쪼갤 필요가 없다. 단, 주변을 비추는 광원은 아니다 |
| **PBR 텍스처**: Color·Normal·Roughness·Metalness 4종 | 정식 | 사진 같은 재질의 기본 |
| 텍스처 최대 해상도 | 문서 버전마다 1024 또는 4096으로 다르게 적혀 있다 | **작업 전에 실제 업로드로 확인**한다 |
| 화면 공간 반사(SSR) | 2026 크리에이터 로드맵 관련 글 목록에 제목만 보임. **확정 아님** | 나중에 나오면 바꿔 끼울 수 있게 반사 시스템을 모듈로 분리해 둔다 |
| 머티리얼 응답 개선(스페큘러 세부 제어) | RDC26 발표, 2027년 중반 예정 | 지금은 해당 없음 |
| ReShade 같은 외부 셰이더 | 플레이어 PC에 직접 설치하는 방식이라 **게임에 넣을 수 없다**. 규정 위반 소지도 있다 | 쓰지 않는다 |

## 1. 실시간 반사 (젖은 바닥에 네온이 비치는 것) → **거울 지오메트리 기법**

레퍼런스 밤 장면의 핵심은 젖은 바닥에 비친 네온이다. 로블록스 `Reflectance`는 하늘만 비춘다. 그래서 이렇게 한다.

**원리**: 바닥 아래에 도시를 **위아래로 뒤집어 한 벌 더 만들고**, 바닥(또는 물웅덩이 부분)을 반투명하게 해서 아래가 비쳐 보이게 한다. 로블록스 쇼케이스에서 실제로 쓰는 기법이다.

**이 프로젝트에 특히 유리한 이유**: 도시를 코드(`BuildKit`/`WorldBuilder`)로 생성한다. 그래서 생성할 때 **뒤집힌 저해상도 복제본도 같이 만들 수 있다.**

구현 세부
- **파츠 뒤집기 수식**: 바닥 높이 `h`를 기준으로 위치는 `(x, 2h − y, z)`로 옮긴다. 회전은 `M·R·M`(`M = diag(1, −1, 1)`)으로 바꾼다. 상자·원기둥처럼 대칭인 파츠는 이 수식이 정상 회전이 되어 그대로 뒤집힌다.
- **MeshPart**는 음수 스케일이 안 된다 → Blender에서 **좌우 반전 메시를 따로 내보내** 쓴다.
- **복제본은 가볍게**: 실루엣·창 불빛·간판·광고(발광)만 남기고 작은 소품은 뺀다. `CastShadow = false`, `CanCollide/CanQuery/CanTouch = false`.
- **클라이언트 전용**으로 만들고, 카메라 주변 반경(예: 300스터드)만 켠다. 품질 low에서는 끈다.
- **바닥 처리 2가지**
  - (A) 도로 전체 반사: 도로 파츠를 투명도 0.35~0.55 + 어두운 색으로 한다. 위에 노멀맵이 있는 얇은 층(MaterialVariant, 물결 노멀)을 깔아 반사를 일렁이게 한다.
  - (B) **물웅덩이만 반사(추천)**: 도로는 불투명으로 두고, 물웅덩이 모양 영역만 투명하게 뚫는다. 비용이 훨씬 적고 더 사실적이다.
- **충돌 확인**: 지하철 입구처럼 지하 공간이 있는 곳은 거울 영역에서 뺀다.
- 등급: **B(체감 거의 동일)**. 밤·비 장면 품질이 가장 크게 오른다.

## 2. 유리 빌딩에 도시가 비치는 것 → **도시를 찍은 스카이박스(큐브맵)**

유리와 금속은 스카이박스를 반사한다(`EnvironmentSpecularScale = 1`). 그러면 **스카이박스 자체에 도시가 들어 있으면** 유리 빌딩에 도시가 비친다.

- 도시 중심에서 90° 시야로 6방향을 렌더링해 스카이박스 6장을 만든다. 렌더링은 Blender(도시 프록시를 내보내서)로 하거나, Studio에서 카메라를 돌려 캡처한다.
- 스카이박스 아래쪽 절반은 먼 스카이라인 배경 역할도 한다(L5 원경). 실제 원경 메가타워와 이어지게 맞춘다.
- 낮/밤 두 벌을 만들고, 시간 전환에 맞춰 바꾼다.
- 등급: **B**. 낮 장면의 유리 커튼월이 레퍼런스처럼 하늘과 도시를 비춘다.

## 3. 전역 조명(빛이 벽에 튕겨 주변을 물들이는 것) → **베이크 + 가짜 반사광**

1. **AO·간접광 베이크(정적 건물)**: Blender에서 모듈 건물을 만들고 **AO(구석 그늘)와 간접광**을 텍스처에 굽는다(디노이즈 필수). SurfaceAppearance ColorMap에 곱해서 넣는다.
   - 직사광(해)은 굽지 않는다. 직사광은 로블록스 실시간 조명에 맡겨서 낮/밤 전환이 되게 한다.
   - 로블록스 문서는 "조명을 구운 텍스처는 실제 조명과 안 맞으면 어색하다"고 경고한다. 그래서 **AO와 약한 간접광만** 굽는다.
2. **반사광 가짜 조명(fill light)**: 햇빛을 정면으로 받는 큰 면 앞에 **그림자 없는 넓은 SurfaceLight/PointLight**를 따뜻한 색, 낮은 밝기로 둔다. 길바닥의 빛이 건물 아래쪽을 물들이는 효과가 난다. 밤에는 큰 광고판 앞에 광고 색으로 둔다(광고 빛이 거리를 물들임).
3. **접촉 그림자**: 건물과 바닥이 만나는 선, 소품 밑에 어두운 그라디언트 데칼을 깐다.
- 등급: **B**. 광원 수 예산(화면 안 40개)을 넘지 않게 배치한다.

## 4. 사진 같은 질감 → **CC0 사진 텍스처 + Blender 모델 + 발광 마스크**

- **텍스처 출처(저작권 문제 없음)**: Poly Haven, ambientCG 같은 **CC0(누구나 상업적으로 무료 사용)** PBR 텍스처. 콘크리트, 아스팔트, 녹슨 금속, 타일, 유리, 페인트 벽을 받아 로블록스 해상도에 맞게 줄이고 업로드한다. 출처를 `docs/asset-ledger.md`에 적는다.
- **모델**: Blender를 Python(bpy)으로 **헤드리스 실행**해 모듈 건물 키트(창 모듈, 발코니, 실외기, 비상계단, 간판 프레임)를 절차적으로 만든다. UV, 베이크, FBX 내보내기까지 자동으로 한다. CC0 소품 모델(Poly Haven 등)도 쓸 수 있다.
- **업로드**: Open Cloud Assets API로 이미지와 모델을 업로드한다(지원 형식은 문서에서 확인). API 키는 사용자가 환경 변수로 넣는다.
- **발광 마스크**: 창문 불빛 패턴, 간판 글자, 광고 화면을 마스크로 만들어 텍스처 안에서 빛나게 한다(밤 창 불빛 무작위 패턴도 마스크 몇 종으로 해결).
- **삼각형 예산**: MeshPart 하나당 엔진 한도 안에서, 가까운 것은 촘촘하게, 먼 것은 단순하게(LOD 2~3단계).
- 등급: **A~B**. 로블록스에서 가장 사실적인 쇼케이스들이 쓰는 방식이다.

## 5. 후처리 효과 (색수차·렌즈 플레어·모션 블러·볼류메트릭)

| 효과 | 방법 | 등급 |
|---|---|---|
| **렌즈 플레어** | 해 방향을 화면 좌표로 바꾸고, 해→화면 중앙 선 위에 플레어 스프라이트 5~8개(ImageLabel) 배치. 레이캐스트로 해가 가려지면 서서히 사라짐 | A |
| **진짜 색수차** | ViewportFrame 3장(R/G/B)에 장면을 다시 그려 어긋나게 겹친다. 무거워서 **능력 발동 0.3초 같은 짧은 순간 + 저해상도 프록시**에만 쓴다. 평소에는 가장자리 띠 방식 | B(순간) / C(상시) |
| **모션 블러** | 같은 ViewportFrame 방식으로 이전 프레임 잔상을 겹친다. 대시·크로노 때만 | C |
| **볼류메트릭 빛줄기** | 부드러운 원뿔 텍스처 Beam 여러 겹 + 떠다니는 먼지 파티클 + SunRays | B |
| **열기 아지랑이** | 투명한 굴절 느낌의 Glass 재질 판 + 노멀 일렁임(제한적) | C |
| **필름 그레인·비네팅** | GUI 레이어(기존 계획) | A |

## 6. 사람·차의 사실감
- **보행자**: 기본 아바타 체형은 블록 느낌이다. 대신 ① 사실 비율 스킨드 메시 인간형(CC0 또는 직접 제작 후 로블록스 리그에 맞춤) ② 레이어드 클로딩으로 옷 다양화 ③ 걷기·대기·전화·담배 등 애니메이션 5종 이상. 멀리 있는 사람은 저폴리 LOD.
- **차량**: Blender로 자체 디자인한 차 3~5종 + 도색 변형, 유리·크롬 PBR, 발광 마스크 전조등.
- 등급: **B**.

## 7. 그래도 정말 안 되는 것과 최선의 대체
| 항목 | 이유 | 최선의 대체 |
|---|---|---|
| 레이 트레이싱 수준의 실시간 GI | 엔진에 없음 | §3 베이크 + 가짜 반사광 |
| 모든 표면의 실시간 반사 | 엔진에 없음(SSR은 미확정) | §1 거울 지오메트리(바닥) + §2 도시 큐브맵(유리) |
| 플레이어 그래픽 품질 강제 | 플레이어 설정이 우선 | 품질 8~10에서 레퍼런스급, 낮은 품질에서도 구도·색이 무너지지 않게 설계 |
| 화면 전체 커스텀 셰이더 | 엔진에 없음 | §5 조합 |

→ 이 기법들을 다 쓰면 정지 화면 기준 체감은 레퍼런스의 90% 안팎까지 갈 수 있다(우리 판단). 나머지는 엔진 업데이트(SSR 등)가 나오면 모듈을 바꿔 끼워 채운다.

## 8. Claude Code에 필요한 준비물 (사용자가 해 줄 것)
1. **Blender 설치**(무료). Claude Code가 `blender --background --python`으로 모델링·베이크·내보내기를 한다.
2. **Open Cloud API 키**(Asset 업로드 권한). 저장소에 넣지 말고 환경 변수로 준다.
3. 업로드할 그룹/계정 ID.
4. 네트워크: Poly Haven·ambientCG에서 텍스처를 내려받을 수 있어야 한다.
