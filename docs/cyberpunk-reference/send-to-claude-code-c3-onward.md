> **보내는 법**: C2를 하고 있는 그 세션에 아래 `---` 아래 전체를 붙여 넣으세요. 지금 하는 C2는 그대로 끝내고, **C2가 끝난 다음부터** 이 절차를 따르게 써 두었습니다.
> 레퍼런스 사진(낮 거리 사진)과 지금 게임 화면 스크린샷을 같이 첨부하면 좋습니다.

## 0. 먼저 — C2는 건드리지 않는다
- 지금 진행 중인 **C2(행인 30종·조합·군중·애니메이션·소품 피하는 길)는 원래 계획대로 끝낸다.** 이 메시지 때문에 C2 범위를 바꾸거나 C2 파일을 고치지 않는다.
- C2를 마치면 보고하고, **그다음부터 아래 새 절차(C3~C12)**를 따른다. 기존 C3~C7 계획과 그래픽 패스(G0~G12)는 아래 순서로 **합쳐서 대체**한다.
- 기존 규칙은 그대로다: 한국어, `cyber-3v3.rbxl` 저장 금지, `rojo build -o cyber-rpg.rbxl` 금지, computer-use 금지, 기능 브랜치 커밋(+ `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`), 단계마다 Lune 테스트 전부 통과, 다른 게임의 이름·로고·브랜드·특정 장소 복제 금지.

## 1. 왜 바꾸나 — 지금 문제
- **쓸데없는 간판이 너무 많다.** 간판이 많다고 사이버펑크가 되지 않는다. 지금은 "간판 박람회"처럼 보이고 레퍼런스의 분위기가 안 난다.
- 원인 중 하나는 그래픽 패스 G4의 **"화면당 간판 25개 이상" 기준**이다. 이 기준은 틀렸다. **폐기한다.** 개수 대신 아래 "구성 규칙"으로 판단한다.
- 레퍼런스의 분위기는 간판이 아니라 **① 거대한 건축 ② 빛과 대기 ③ 절제된 색 ④ 사람 눈높이의 생활 잡동사니 ⑤ 소수의 압도적인 광고**에서 나온다.

## 2. 아트 디렉션 — 레퍼런스 분위기의 원리 (이걸 기준으로 모든 판단)

### 2-1. 화면 구성 비율 (낮 기준, 고정 촬영 지점에서 눈대중 + 도구 측정)
| 요소 | 화면 면적 비율 목표 |
|---|---|
| 건축(콘크리트·유리·금속 구조물) | 50~65% |
| 하늘·대기(먼 건물이 연하게 날아가는 부분 포함) | 15~30% |
| 거리층(도로·보도·사람·차·소품) | 15~25% |
| **간판·광고·스크린 합계** | **5~12%** (번화가 최대 15%, 기업 구역 5% 이하) |
| 채도 높은 네온·원색 포인트 | 전체의 10% 이하 |

### 2-2. 건축이 주인공
- **거대한 콘크리트 구조**: 브루탈리즘 계열의 육중한 덩어리, 굵은 기둥, 층마다 깊은 처마와 띠, 계단식 후퇴층.
- **기반 시설이 겹친다**: 고가도로, 모노레일 선로와 교각, 육교, 공중 통로, 배관, 환기탑. 도로 위를 가로지르는 구조물이 화면마다 1~2개 있어야 한다.
- **스케일 대비**: 사람 키의 수십~수백 배 높이. 고개를 들면 끝이 안 보인다.
- 큰 면은 대부분 **간판 없는 맨 콘크리트·유리·패널**이다. 빈 면이 있어야 광고가 산다.

### 2-3. 구역마다 스타일이 다르다 (허브를 2~4구역으로 나눔)
| 스타일 | 느낌 | 재질·색 | 간판 |
|---|---|---|---|
| **빈민·재활용풍** | 임시변통, 덧댄 증축, 낡음 | 녹, 비닐 천막, 컨테이너, 합판, 덕트 테이프, 주황 나트륨등 | 손으로 만든 작은 간판, 고장 난 네온 몇 개 |
| **싸구려 화려풍** | 80년대풍 플라스틱, 원색, 들뜬 유흥 | 원색 플라스틱, 크롬, 마젠타·노랑 | 번화가 한 블록에 집중, 세로 간판 묶음 |
| **기업·군사풍** | 각지고 기능적, 위압적 | 회색 콘크리트, 검은 유리, 경고 노랑, 표기 문자 | 거의 없음. 건물 꼭대기 로고 1개, 출입 표지 |
| **부유층 고급풍** | 깨끗하고 미니멀, 비싼 재료 | 흰 석재, 투명 유리, 금색, 녹지 | 작은 금속 로고, 큰 고급 홀로그램 1개 |

### 2-4. 간판·광고는 "계층"으로 (개수 아님)
| 계층 | 화면당(번화가 기준) | 규칙 |
|---|---|---|
| **영웅 광고**: 건물 한 면을 덮는 스크린·홀로그램 | 1~2개 | 화면 구도의 초점. 움직인다. 멀리서도 읽힌다 |
| **건물 브랜드**: 옥상·꼭대기 로고 | 1~3개 | 그 건물의 주인을 표시. 크고 단순하다 |
| **중형 광고판**: 프레임 있는 빌보드, 세로 간판 묶음 | 3~8개 | 도로·교차로를 향해 설치. 받침 구조와 케이블이 보인다 |
| **가게 간판**: 1~2층 상점 전면 | 가게마다 1개 | 반드시 실제 가게 입구 위. 가게가 없으면 간판도 없다 |
| 작은 표지(번지, 경고, 전단, 그래피티) | 자유 | 질감 역할. 멀리서는 안 읽혀도 된다 |

**금지 규칙**(이유 없는 간판 = 삭제)
- 공중에 떠 있거나, 받침·프레임·케이블 없이 벽에 그냥 붙은 간판
- 벽을 향하거나, 다른 간판·구조물에 가려 안 보이는 간판
- 가게 입구가 없는데 붙은 가게 간판
- 같은 디자인이 한 화면에 3개 이상 반복되는 것
- 모든 층·모든 면에 고르게 뿌린 간판(번화가도 "몰린 곳"과 "빈 곳"이 있어야 한다)
- 글자만 있고 브랜드 정체성(로고 모양·색 체계)이 없는 간판

### 2-5. 빛과 색
- **낮**: 노란빛 스모그 섞인 강한 햇빛, 또렷한 그림자, 그늘은 청록 계열. 전체 채도는 낮게, 포인트만 진하게.
- **밤**: 모든 곳이 밝지 않다. **빛 웅덩이와 어둠의 대비**. 광고 빛이 주변 벽과 바닥을 물들이고, 젖은 바닥에 비친다.
- 기본 팔레트: 콘크리트 회색·베이지 + 나트륨 주황 + 청록. 포인트 색: 노랑·마젠타·시안·빨강을 **조금만**.

### 2-6. 사람 눈높이는 "잡동사니"로 채운다 (간판 대신)
- 실외기, 배관, 전선 다발, 환기구, 철망, 비계, 비닐 천막, 쓰레기 봉투, 박스, 바리케이드, 콘크리트 블록, 노점, 자판기, 오토바이, 화분, 물웅덩이, 증기.

### 3-1. C3 상세 — 분위기 감사와 간판 정리
1. **목록 만들기**: 허브의 모든 간판·광고·스크린·홀로그램을 목록으로 뽑는다(`docs/environment/signage-inventory.md`). 항목마다 위치, 크기, 계층, 붙은 건물이나 가게, 디자인 ID, 화면 노출도를 적는다.
2. **판정**: 항목마다 **유지 / 이동 / 축소 / 삭제** 중 하나를 고르고 이유를 적는다. 판정 기준은 2-4 계층 규칙과 금지 규칙이다.
3. **규칙 모듈**: 판정과 배치 규칙을 `SignageRules`(순수 로직)로 만들고 Lune 테스트를 붙인다. 예: 가게 없는 가게 간판 거부, 화면당 같은 디자인 3개 이상 거부, 구역별 면적 상한, 받침 구조 필수.
4. **정리 실행**: BuildKit/WorldBuilder의 간판 생성 코드를 규칙 모듈을 거치게 바꾼다. 간판 수는 **절반 이하로 줄이는 것을 예상**하되, 숫자보다 구성 규칙 통과가 기준이다.
5. **빈 면 확보**: 간판을 뺀 자리는 콘크리트 질감, 띠, 창, 배관으로 채워 "빈 벽인데 밋밋하지 않게" 만든다.
6. **측정 도구**: 개발용 도구로 고정 촬영 지점마다 **간판 화면 면적 비율, 계층별 개수, 같은 디자인 반복 수, 네온 포인트 비율**을 계산해 보여 준다.
7. **보고**: 촬영 지점 5곳의 정리 전후 사진(낮·밤), 측정표, 삭제·이동한 간판 수, 레퍼런스와 아직 다른 점 상위 5개.

### 3-2. 단계마다 공통 검증
| 기준 | 목표 |
|---|---|
| 간판·광고 화면 면적 | 구역 기준 안(번화가 ≤ 15%, 기업 ≤ 5%) |
| 영웅 광고 | 번화가 화면에 1~2개, 나머지 구역은 0~1개 |
| 같은 디자인 반복 | 화면당 ≤ 2 |
| 이유 없는 간판(금지 규칙 위반) | 0 |
| 건축 비율 / 하늘 비율 | 50~65% / 15~30% |
| 도로 위를 가로지르는 구조물 | 화면당 1~2개 |
| 네온·원색 포인트 | ≤ 10% |
| 구역 구분 | 사진만 보고 4구역 스타일이 구별된다 |
| 레퍼런스 나란히 비교 | "어색한 점 상위 5개"와 다음 수정안 |

## 4. 판단이 애매하면
- 간판을 더 넣을지 고민되면 **넣지 않는다.** 대신 건축 디테일이나 잡동사니, 빛으로 채운다.
- 구역 배치(어디를 번화가로, 어디를 기업 구역으로 할지)는 C3 보고 때 **지도 시안 2개**를 보여 주고 내가 고르게 한다.

## 5. 시작
지금은 C2를 계속한다. C2를 마치면 C2 결과를 보고하고, 이어서 **C3 1~2번(목록과 판정표)**까지 해서 보여 준 뒤 멈춘다.
