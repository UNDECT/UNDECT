# 사이버펑크 1인칭 액션 RPG — 레퍼런스 인게임 정밀 조사 + 로블록스 구현안

> 기준: 레퍼런스 게임 2.x(2.0 대개편 ~ 2.3) + 확장팩 기능.
> 목적: "왜 사이버펑크 느낌이 나는가"를 **화면·소리·손맛 단위**로 쪼개 놓고, 각 항목을 로블록스에서 어떻게 재현할지 정리한다.
> 수치 중 `≈`가 붙은 것은 패치·등급마다 달라 정확히 확정할 수 없는 값이다. 체감 기준 **권장값**으로 쓴다.
> 프로젝트 규칙상 **다른 게임의 이름·에셋은 쓰지 않는다.** 이 문서는 레퍼런스 분석용이다. 구현할 때는 아래 "자체 명칭"을 쓰고, 색·UI 배치도 레퍼런스를 그대로 베끼지 말고 **같은 감각을 주는 자체 디자인**으로 만든다.

## 0. 레퍼런스가 "사이버펑크처럼 느껴지는" 핵심 7요소

기능 목록보다 이게 먼저다. 지금 프로젝트에서 "느낌이 안 나는" 이유는 대부분 여기서 빠졌기 때문이다.

1. **디지털 화면 레이어**: 주인공의 눈이 사이버 안구다. 그래서 HUD·스캔·해킹·피격이 전부 "눈 속 화면이 지지직거리는" 연출로 나온다. 글리치, 색수차(RGB 분리), 스캔라인, 화면 찢김이 모든 이벤트에 붙어 있다.
2. **능력 발동 = 시간·색·소리 3중 변화**: 시간 가속 능력을 켜면 ① 세상이 느려지고 ② 화면 색이 바뀌고 ③ 소리가 먹먹해지며 심장 박동이 들린다. 셋 중 하나만 있으면 밋밋하다.
3. **정보 과잉 HUD**: 적 머리 위 체력·레벨·탐지 게이지, 데미지 숫자, 피격 방향 표시, 미니맵, 퀘스트 문구, 탄약, 쿨다운 등. 정보가 화면에 빽빽하다.
4. **네온 × 어둠 × 비**: 어두운 거리, 강한 네온 원색(마젠타·시안·노랑), 젖은 바닥 반사, 증기, 안개, 홀로그램 광고. 수직으로 높은 메가빌딩.
5. **사람이 많은 도시**: 군중, 차, 하늘을 나는 차량, 노점, 경찰. "도시가 살아 있다"는 소음.
6. **무겁고 시끄러운 총**: 강한 반동, 큰 총구 화염, 탄피, 화면 흔들림, 맞으면 튀는 피와 부위 절단.
7. **크롬(기계 몸)의 손맛**: 팔에서 칼날이 펼쳐지는 기계음, 사이버웨어 설치 때 시야가 부팅되는 연출.

## 1. HUD(화면 고정 UI) — 전체 배치

### 1-1. 레퍼런스 배치

| 위치 | 내용 | 세부 |
|---|---|---|
| 좌상단 | 체력 바 + 캐릭터 레벨 숫자 | 가로로 긴 바. 맞으면 잃은 만큼 밝은 잔상이 남았다가 천천히 줄어든다(지연 감소 바). |
| 체력 바 아래 | 상태 이상 아이콘(출혈·화상·전기·독·버프) | 아이콘마다 남은 시간 원형 게이지 |
| 체력 바 아래 | **RAM 바** | 칸(셀)으로 나뉜 바. 해킹 메뉴에서 대상을 고르면 쓸 칸이 미리 깜빡인다. |
| 체력 근처 | 스태미나 바 | 소모할 때만 나타나고 가득 차면 사라진다 |
| 좌하단 | 회복 아이템 충전 수, 수류탄 충전 수, **사이버웨어 능력 충전 게이지** | 쿨다운이 원형으로 찬다 |
| 우하단 | 무기 패널: 현재 탄 / 예비 탄(크게), 무기 이름, 장착 슬롯 3칸 | 탄이 적으면 숫자 색이 바뀌고 깜빡인다 |
| 우상단 | 미니맵(둥근 사각형) + 수배 별 | 적은 빨간 점, 시야 원뿔. 전투 중에는 테두리가 빨갛게 바뀐다 |
| 미니맵 아래 | 현재 퀘스트 이름 + 목표 문장 + 거리(m) | |
| 화면 중앙 | 무기별 조준선 | 이동·사격 시 벌어진다(동적 확산). 스마트 무기는 별도의 원형 락온 UI |
| 화면 상단 중앙 | 적 넷러너가 나를 해킹 중일 때 경고 바 | 해킹 이름 + % 진행률 |
| 화면 가장자리 | 피격 방향 화살표(붉은 호), 화면 밖 적 위치 화살표 | |

### 1-2. HUD 공통 연출 규칙
- **글리치 등장**: UI는 그냥 나타나지 않는다. 1~3프레임 동안 좌우로 어긋나고 RGB가 분리됐다가 제자리를 잡는다.
- **각진 디자인**: 모서리를 사선으로 깎은 패널, 얇은 외곽선, 작은 보조 숫자·바코드·좌표 같은 장식 텍스트.
- **단일 강조색 + 경고색**: 기본색 하나(레퍼런스는 붉은 계열/노랑 강조), 네트워크·해킹은 시안·청록, 위험은 빨강. **자체 게임은 다른 조합을 쓴다**(예: 기본 마젠타 + 해킹 시안 + 경고 주황).
- **숫자는 모노스페이스 폰트**: 로블록스 `Enum.Font.Code` / `RobotoMono` / `Arcade` 같은 폰트를 쓴다.

### 1-3. 로블록스 구현
| 요소 | 방법 | 등급 |
|---|---|---|
| 각진 패널 | Frame + UIStroke + 모서리에 회전시킨 작은 Frame으로 사선 컷 / UIGradient | A |
| 지연 감소 체력바 | 바 2개(실제/잔상). 잔상은 0.4초 기다렸다가 Tween으로 줄인다 | A |
| RAM 셀 미리보기 | 셀 Frame 배열. 비용만큼 `TweenService`로 깜빡임 | A |
| UI 글리치 등장 | 등장 시 0.12초 동안 Position X를 ±4~10px로 무작위 3번 흔든다. 같은 텍스트를 빨강·시안으로 1~2px 어긋나게 복제해 겹친 뒤 사라지게 한다 | A |
| 동적 조준선 | 4개 막대 Frame. 확산 값(이동속도·연사·조준)에 따라 간격 변경 | A |
| 피격 방향 | 공격자 위치→카메라 기준 각도로 원 둘레에 붉은 호 이미지 회전 배치 | A |

## 2. 화면 효과(포스트 프로세싱) — 상황별

### 2-1. 레퍼런스에서 효과가 붙는 상황 전체 목록

| 상황 | 화면에 일어나는 일 |

| 적이 내 사이버웨어 오작동 | 능력 아이콘에 X, 화면 깜빡임 |

| 스캐너 | §4-1 참고 |
| 메뉴 열기/닫기 | 글리치 트랜지션 + 배경 흐림(피사계 심도) |
| 대화 | 배경 피사계 심도로 상대에게 초점 |
| 빠른 이동 / 로딩 | 디지털 공간 연출(와이어프레임·데이터 입자). **자체 연출로 대체** |
| 사망 | 화면이 기울며 쓰러지고, 색이 빠지고, 신호가 끊기는 노이즈 |
| 과부하 상태(사이버웨어 한도 초과 광폭화) | 붉은 색조, 글리치, 환청 같은 속삭임 |

### 2-2. 로블록스 구현 — 화면 효과 엔진(`ScreenFX`)

로블록스에는 **사용자 셰이더가 없다.** 화면을 캡처해 다시 그릴 수도 없다. 그래서 아래 조합으로 "흉내"를 낸다.

| 효과 | 로블록스 구현 | 등급 |
|---|---|---|
| 색보정·채도·대비 | `ColorCorrectionEffect`(TintColor, Saturation, Contrast, Brightness) | A |
| 블룸 | `BloomEffect` + Neon 재질 | A |
| 흐림 | `BlurEffect`(전체), `DepthOfFieldEffect`(초점) | A |
| 비네팅 | ScreenGui 전면 ImageLabel(가장자리가 진한 방사형). 이미지를 업로드하지 않으려면 Frame 4개 + UIGradient 투명도로 만든다 | A |
| **색수차(RGB 분리)** | 진짜 분리는 불가. ① 화면 가장자리에만 빨강/시안 반투명 띠 2장을 서로 반대로 2~6px 흔든다 ② 같은 순간에 ColorCorrection Tint를 빨강↔시안으로 1프레임씩 교대한다. 체감상 꽤 비슷하다 | C |
| 스캔라인 | 가로 1px 줄무늬를 반복하는 이미지(직접 업로드하거나 `EditableImage`로 런타임 생성) + 아주 천천히 위로 스크롤 | B |
| **글리치/화면 찢김** | 화면 전체를 덮는 "글리치 슬라이스" 풀: 가로로 긴 Frame 8~20개, 무작위 높이(2~40px)·X 오프셋·색(검정, 시안, 마젠타, 흰색 노이즈)·투명도. 30~60ms마다 다시 섞고, 효과 시간 동안만 켠다. 카메라 Roll ±1° 떨림과 HUD 오프셋을 함께 준다 | B |
| 필름 그레인 | 노이즈 이미지를 0.05초마다 무작위 오프셋. 투명도 0.92~0.96 | B |
| 카메라 펀치·흔들림 | `Camera.CFrame`에 스프링 기반 회전 오프셋(Shake 모듈) | A |
| FOV 펀치 | Camera.FieldOfView Tween(+5~12) | A |
| 소리 먹먹함 | `SoundGroup` + `EqualizerSoundEffect`(고음 감쇠) / `ReverbSoundEffect` | A |

**핵심 설계**: 모든 효과를 "프리셋 + 강도(0~1) + 지속시간"으로 정의하고, 여러 효과가 동시에 오면 **가중 합산**한다(예: 피격 붉은 비네팅 + 시간 가속 청록 틴트가 동시에 오는 경우).

## 3. 1인칭 무기·전투

### 3-1. 레퍼런스 총기 손맛
- **반동**: 총마다 고유 반동 패턴(위로 튀고 좌우로 흔들림). 카메라가 튀고 무기 모델은 더 크게 튄다. 연사하면 누적된다.
- **무기 흔들림(sway)**: 시선을 돌리면 총이 살짝 늦게 따라온다(관성). 달리면 총을 비스듬히 내린다(스프린트 자세). 걸을 때 약한 상하 흔들림.
  - ⚠️ 현재 프로젝트는 걷기 흔들림을 **완전히 없앴다.** 사용자 요청이라 유지하되, **시선 회전 관성(sway)과 스프린트 자세는 걷기 흔들림과 별개**다. 이게 없으면 총이 화면에 "붙어 있는" 느낌이 난다. 옵션으로 넣고 사용자에게 확인받는다.
- **총구 화염 + 탄피 + 연기**, 탄착점에 재질별 효과(금속 불꽃, 콘크리트 먼지, 살점), 총알 궤적(예광탄).
- **재장전**: 탄창이 남아 있을 때와 빈 탄창일 때 애니메이션이 다르다(빈 탄창은 노리쇠/장전 손잡이 동작 추가).
- **무기 살펴보기(Inspect)** 애니메이션.
- **조준(ADS)**: 무기를 눈앞으로 가져오며 FOV가 줄어든다. 고배율 스코프는 렌즈 화면 + 주변 검정 + 숨 참기 흔들림.

### 3-2. 무기 기술 계열 3종 (레퍼런스의 핵심 차별점)

| 계열 | 동작 | 화면 연출 | 로블록스 구현 | 등급 |
|---|---|---|---|---|
| **파워형** | 총알이 벽에 튕긴다(도탄) | 보조 사이버웨어가 있으면 도탄 궤적 선을 미리 보여 준다 | 레이캐스트 후 법선 반사(`d - 2(d·n)n`)를 1~3회. 미리보기는 Beam/Part 선 | A |
| **테크형** | 마우스를 누르고 있으면 충전, 놓으면 벽을 관통 | 조준선 주변에 충전 게이지, 충전 완료 시 총이 빛나고 소리. 관통하면 벽 뒤 적 실루엣 | 충전값 0~1. 관통은 레이캐스트를 맞은 지점에서 조금 앞으로 옮겨 반복하며 두께·재질별로 데미지 감소. 벽 뒤 적은 Highlight(AlwaysOnTop) | A |
| **스마트형** | 적에게 자동 락온, 총알이 휘어서 날아간다 | 적 몸에 원형 락온 마커가 생기고, 조준선 주변에 락온 원이 여러 개. 미세 미사일 | 화면 중앙 원뿔 안의 적을 락온. 투사체는 매 프레임 목표 쪽으로 방향을 보간(유도) | A |

### 3-3. 전투 피드백
- **데미지 숫자**: 맞은 위치에서 위로 떠오르며 사라진다. 치명타는 크고 다른 색, 속성별 색(물리 흰색, 열 주황, 전기 파랑, 화학 녹색).
- **히트 마커**: 조준선에 X. 헤드샷·처치 시 모양과 색이 바뀌고 전용 "딸깍" 소리.
- **처치 피드백**: 적 쓰러짐(랙돌), 부위 절단(산탄총·칼날·파워암), 피 튀김, 벽에 혈흔.
- **적 머리 위 UI**: 체력바, 레벨/위협도 아이콘(너무 강하면 해골), 탐지 게이지.

## 4. 넷러닝(해킹)

### 4-1. 스캐너 모드 — "사이버 안구로 세상을 보기"
**레퍼런스 동작**
1. 스캔 키를 누르고 있으면 스캐너 모드가 된다.
2. **전투 중이면 시간이 크게 느려진다**(정확한 배율은 확정할 수 없음, 체감 ≈ 0.2~0.3배).
3. 화면 색이 단색 톤으로 바뀌고(레퍼런스는 노란 톤), 비네팅·스캔라인이 붙는다.
4. **하이라이트**: 적은 빨강, 해킹 가능한 장치는 노랑/초록, 카메라·포탑은 별도 색, 상호작용·전리품 강조. 벽 너머도 보이는 경우가 있다(핑 해킹 후).
5. 화면 중앙의 대상을 바라보면 정보 패널이 뜬다: 이름, 소속, 위협도, **약점/저항 속성**, 현상금, 상태.
6. 화면 한쪽에 **해킹 목록**이 세로로 나온다: 해킹 이름 / RAM 비용 / 업로드 시간 / 쿨다운. 고르면 RAM 바에 쓸 칸이 미리 표시된다.
7. 대상이 처음 보는 것이면 **스캔 진행 바**가 차오른다.
8. 마우스 휠로 **광학 줌**(단계 배율)이 된다.
9. 네트워크로 연결된 장치·적 사이에 **연결선**이 보인다.

**로블록스 구현(B)**
- `ScannerController`(클라이언트): 키를 누르면 ColorCorrection 프리셋 + 스캔라인 + Highlight 매니저 ON.
- 시간 감속은 §5-0 `TimeScale` 시스템을 쓴다(멀티플레이어라서 "전역 정지"는 하지 않는다).
- 대상 선택: 화면 중앙 레이캐스트 + 실패하면 화면 중앙 근처 원뿔 안에서 가장 가까운 대상(자석 보정).
- 정보 패널: 대상에 붙은 Attribute(이름, 소속, 약점) 읽기.
- 연결선: 같은 네트워크 ID를 가진 대상끼리 `Beam`(얇은 시안, 텍스처 스크롤).
- **Highlight는 동시에 31개까지만 렌더된다.** 그래서 거리·우선순위로 상위 31개만 켜는 풀을 만든다.
- 현재 프로젝트는 "E 짧게=즉시 해킹, 길게=휠"이다. 이건 유지하고, **스캐너 모드를 별도 키(예: Tab 홀드)로 추가**하면 정보·감속·하이라이트까지 갖출 수 있다.

## 5. 사이버웨어 — 발동 연출 정밀 분석

### 5-0. 공통 기반: 시간 배율 시스템(`TimeScale`) — 가장 중요
로블록스에는 **전역 시간 감속이 없다.** 그리고 멀티플레이어라서 한 명이 시간을 멈추면 다른 사람도 영향을 받는다.

**권장 구조**
- 모든 "느려질 수 있는" 것(적 AI, 적 애니메이션, 적 투사체, 파티클, 문·엘리베이터, 소리)은 매 프레임 `dt * TimeScale.get(entity)`를 쓴다.
- 서버: 시간 가속 사용자 반경 R(예: 60스터드) 안의 NPC에 배율을 건다. 여러 명이 동시에 쓰면 가장 작은 배율을 쓴다.
- 애니메이션: `AnimationTrack:AdjustSpeed(base * scale)`.
- 이동: `Humanoid.WalkSpeed = base * scale`. 떨어지는 물리체는 `AssemblyLinearVelocity`를 배율로 깎고 중력을 상쇄하는 `VectorForce`를 쓴다.
- 투사체: 자체 시뮬레이션(레이캐스트 스텝)이라 `dt * scale`만 곱하면 된다.
- 파티클: `ParticleEmitter.TimeScale` 속성을 쓴다(엔진이 지원).
- 소리: 주변 소리 `PlaybackSpeed` 0.5~0.7 + 저역 통과 EQ. 내 소리는 그대로.
- 다른 플레이어에게 보이는 모습: 사용자가 매우 빠르게 움직이고 **잔상**이 남는다(캐릭터 파츠를 반투명 네온으로 복제해 0.25초 동안 페이드). 레퍼런스 1인칭에는 잔상이 없지만, 멀티플레이 시점에서는 이게 가장 잘 읽힌다.

### 5-1. 시간 가속 OS(자체 명칭: 크로노) — 레퍼런스의 대표 능력
**레퍼런스 발동 순서(체감 기준)**
| 시간 | 일어나는 일 |
|---|---|
| 0.00s | 발동 키. 날카로운 "슉" 상승음 + 낮은 쿵 |
| 0.00~0.25s | 화면 색이 녹청(그린-시안) 톤으로 확 바뀐다. 가장자리 색수차·흐림. 짧은 FOV 펀치 |
| 지속 중 | 세상 ≈ 0.1~0.3배 속도(모델별로 다름). 나는 정상 속도. 주변 소리가 늘어지고 먹먹해지며 **심장 박동/저음 펄스**가 반복. 총알·탄피·피가 공중에 떠 있는 것처럼 천천히 날아감. 잔여 시간 게이지가 줄어듦 |
| 종료 | "펑" 하는 복귀음, 색이 한 번에 돌아옴, 짧은 색수차 |
| 쿨다운 | 좌하단 아이콘 원형 게이지 |
- 일부 모델: 처치 시 지속 시간 연장, 치명타 증가, 조기 해제 시 쿨다운 일부 환급.

**로블록스 구현 레시피(권장값)**
- 발동(0.25s): FOV +10 → +4로 정착, `ColorCorrection` Tint를 자체 색(예: 연청록 `Color3.fromRGB(150,255,230)`), Saturation −0.35, Contrast +0.2. 1프레임 흰 플래시(투명도 0.6). 색수차 띠 0.3초. 카메라 롤 펀치 1.5°.
- 지속: 비네팅 0.5, 스캔라인 약하게, `BlurEffect` 2, 심장 박동 루프(60~70bpm), 주변 소리 EQ.
- 종료(0.15s): 역방향 Tween + "팝" 사운드 + 색수차 0.15초.
- HUD: 조준선 주변 얇은 원형 게이지가 줄어든다.

### 5-2. 반사 신경 계열(자체 명칭: 리플렉스)
| 레퍼런스 장치 | 발동 조건 | 효과 | 연출 |
|---|---|---|---|
| 회피 반응형 | 회피/슬라이드 중에 조준 | ≈2초 짧은 감속 | 시간 가속보다 약한 색 변화, 짧은 "휙" |
| 위기 반응형 | 체력이 일정 이하 | 자동 감속 | 붉은 톤 + 심장 박동 |
| 발각 반응형 | 적에게 발각되는 순간 | 짧은 감속 | 탐지 게이지가 차는 순간 화면 줌 |
| 공중 회피 확장 | 공중에서 발동 | 공중에 떠 있으며 감속 | |
- 로블록스: 같은 `TimeScale`을 짧게(1.5~2초) 쓴다. 등급 B.

### 5-3. 팔 사이버웨어
| 레퍼런스 | 꺼내기 연출 | 공격 | 특수 | 자체 명칭(현재) |
|---|---|---|---|---|
| 팔 칼날 | 전완 장갑판이 열리며 칼날이 접혔다 펴짐. 기계음 "철컥-스릉" | 빠른 연속 베기, 부위 절단 | **충전 도약**: 누르고 있다가 놓으면 적에게 크게 뛰어들어 내리찍기(사거리 큼) | 블레이드 |
| 강화 주먹 | 손등 장갑이 맞물리며 빛남 | 무거운 펀치, 넉백 | 충전 펀치 = 충격파로 주변 적 넘어뜨림, 강제로 문 열기 | 파워암 |
| 모노와이어 | 손목에서 빛나는 와이어가 나와 늘어짐(속성별 색) | 채찍 휘두르기 | 충전 = 넓은 수평 베기. **해킹 슬롯**: 와이어로 맞히면 RAM 없이 해킹 업로드 | 나노와이어 |
| 발사 장치 | 손목이 열리며 발사관 | 폭발 투사체(포물선) | 충전 = 5발 분산 발사 | 런처 |
| 확장팩 신기술 | 약점 분석(적 몸에 약점 표시 → 맞히면 EMP 폭발), 긴급 은신(위기 때 자동 은신), 팔 사이버웨어 해방(위의 충전 기술들) | | | |

**로블록스 구현 포인트**
- 꺼내기 애니메이션이 핵심이다. 칼날을 **여러 부품으로 쪼개 Tween**한다(장갑판 회전 → 칼날 회전·연장). 이미 `GunShapes.luau`처럼 코드로 부품을 조립하므로 같은 방식으로 만든다.
- 와이어: `Beam`(CurveSize0/1을 휘두르는 동안 변화) 또는 Part 체인.
- 충전 도약: 목표 지점으로 포물선 이동(`LinearVelocity`) + 착지 충격파 링(원형 Part 확대·투명화) + 카메라 흔들림.

### 5-4. 다리 사이버웨어
| 레퍼런스 | 효과 | 연출 |
|---|---|---|
| 이단 점프 | 공중에서 한 번 더 점프, 공중 방향 전환 | 발밑 압축 공기 "푸슉" + 작은 링 파티클 |
| 충전 점프 | 점프 키를 누르고 있으면 충전 → 높이 도약 | 화면 하단 충전 게이지, 다리 서보음 |
| 공중 대시 | 공중에서 대시 | 짧은 FOV 펀치 + 바람 소리 |
| 슈퍼히어로 착지 | 공중에서 앉기 → 급강하 후 충격파 | 착지 시 큰 카메라 흔들림, 바닥 균열 데칼, 주변 넉백 |
| 질주 강화 / 무음 이동 | 패시브 | — |
- 현재 프로젝트의 비행·벽타기·그래플은 레퍼런스에 없는 확장이다. 괜찮다. 다만 **이단 점프·공중 대시·슬라이드·대시(회피)** 같은 기본 이동이 없다면 그게 먼저다.

### 5-5. 광학 위장(자체 명칭: 위장)
- 발동: 몸에 물결치는 굴절 왜곡. 1인칭 손·총이 반투명 유리처럼 보인다. 화면 가장자리가 살짝 일렁인다.
- 지속: 적이 나를 놓친다(탐지 게이지가 줄어듦). 공격하면 해제된다.
- 로블록스: 뷰모델 파츠 `Material = Glass`, Transparency 0.6~0.8, 약한 Reflectance. 다른 플레이어에게는 캐릭터를 Glass + Transparency 0.9 + 일렁이는 `ForceField` 재질로 보이게 한다. 등급 B.

### 5-6. 순환계(자체 명칭: 바이오 펌프)
| 레퍼런스 | 효과 | 연출 |
|---|---|---|
| 능동 회복 | 즉시 체력 대량 회복, 긴 쿨다운 | 녹색 펄스 비네팅, 심장 펌프음 |
| 자동 부활 | 체력이 0이 되면 1회 부활 | 화면이 검게 꺼짐 → 심장 박동 2번 → 흰 플래시와 함께 "시스템 재가동" 글리치 → 복귀 |
| 위기 자동 회복 | 체력 낮을 때 자동 회복 | |

### 5-7. 그 외 슬롯(레퍼런스 2.0 기준 전체 슬롯)
| 슬롯 | 대표 효과 | 현재 프로젝트 |
|---|---|---|
| 운영체제 | 시간 가속 / 광폭화(근접 강화·착지 충격파·붉은 화면) / 사이버덱 | 크로노, 레이지, 사이버덱 ✅ |
| 전두엽 | RAM 회복, 치명타, 해킹 보조, 방어 ICE | ❌ |
| 팔 | 위 §5-3 | ✅ |
| 골격 | 체력·스태미나·방어력 | ❌ |
| 신경계 | 반응형 감속, 회피 | 리플렉스 ✅ |
| 외피 | 광학 위장, 방어력 | 위장 ✅ |
| 손 | 스마트 무기 연동, 그립(반동 감소) | ❌ |
| 눈 | 줌, 궤적 표시, 스캔 강화 | ❌ (스캐너 모드가 필요) |
| 순환계 | 회복, 부활 | 바이오 펌프 ✅ |
| 다리 | 위 §5-4 | ✅ |
| 얼굴 | 스캐너 보조, 사회적 보너스 | ❌ |
- **용량(Capacity)**: 사이버웨어마다 용량을 차지한다. 한도를 넘기면(특정 퍼크) 최대 체력이 깎이고 처치 시 확률로 광폭 상태(붉은 화면, 피해·치명타 증가, ≈12초).
- **방어력은 사이버웨어에서 나온다**(2.0 이후).

### 5-8. 시술소(리퍼닥) — 설치 연출
1. 의자에 앉는다 → 화면이 흐려지고 어두워진다.
2. 사이버웨어 화면: 몸 실루엣 + 부위별 슬롯 + 용량 바 + 아이템 비교(초록/빨강 수치).
3. 설치 후 첫 사용: 시야가 **부팅**된다. 격자 보정 패턴, 텍스트 로그 스크롤, 색 테스트, 초점이 맞아 가는 흐림 해제.
- 로블록스: 의자 Seat + 카메라 고정 + DepthOfField. 몸 실루엣은 ViewportFrame에 플레이어 캐릭터 복제 + 천천히 회전. 부팅 연출은 `ScreenFX` 프리셋 `"boot"`(검정 → 격자 → 로그 → 흐림 해제, 2.5초). 등급 A.

## 9. 도시·맵 분위기 (허브 다듬기에 직결)

### 9-1. 레퍼런스 체크리스트
- [ ] **수직성**: 초고층 메가빌딩, 다층 고가도로, 지하보도. 고개를 들면 끝이 안 보인다.
- [ ] **네온 밀도**: 간판이 층층이 겹친다. 여러 언어 글자. 깜빡이고 일부 글자가 고장 나 있다.
- [ ] **홀로그램 광고**: 공중에 떠 있는 거대한 반투명 광고(움직임).
- [ ] **젖은 바닥 반사**: 비가 안 와도 바닥이 젖어 네온이 비친다.
- [ ] **대기**: 안개, 스모그, 증기 배출구, 빛줄기(볼류메트릭).
- [ ] **군중**: 길에 사람이 많다. 총을 쏘면 웅크리고 도망간다.
- [ ] **교통**: 차가 다니고, 하늘에 비행 차량이 줄지어 지나간다.
- [ ] **거리 소품**: 자판기, 노점, 쓰레기 더미, 그래피티, 철망, 에어컨 실외기, 전선 다발, 광고 스크린, 공중전화형 단말기.
- [ ] **구역별 색 정체성**: 부유층(깨끗한 흰색·파랑), 빈민가(녹·주황 나트륨등), 유흥가(마젠타·보라), 공업지대(회색·노랑 경고).
- [ ] **낮/밤·날씨**: 낮엔 노란 스모그, 밤엔 네온. 비·안개·모래폭풍.
- [ ] **소리**: 사이렌, 광고 방송, 군중 웅성임, 비, 차 경적, 상점 음악이 위치마다 다르다.

## 12. 시점
- 레퍼런스: **도보는 항상 1인칭**. 3인칭은 운전(선택), 거울, 사진 모드, 일부 컷신에만 쓴다.
- 결론: 현재 "항상 1인칭" 방향이 레퍼런스와 일치한다. 차량을 넣는다면 그때만 3인칭 옵션을 준다. → 아직 답하지 않은 1/3인칭 질문에 이렇게 제안하면 된다.

## 13. 엔진 한계 요약 (반드시 대체 연출을 쓸 것)
