- computer-use로 Studio를 열지 않는다. 대신 **Studio 확인은 네가 직접 한다**(이미 연결된 Studio 연동 도구로 플레이 테스트, 코드 실행, 출력 로그·스크린샷 확인). cyber-3v3.rbxl을 저장하는 동작은 확인 중에도 절대 하지 않는다. 직접 확인할 수 없는 것(손맛 판단, 모바일 실기기, 2인 이상 협동)만 나에게 요청한다.

- 각 Phase가 끝날 때마다 `~/.rokit/bin/lune.exe run tests/run.luau`를 돌려 전부 통과해야 한다(현재 514개). 새로 만드는 순수 로직 모듈(TimeScale, 확산 계산, 반사 계산, 미니게임 판정, 효과 합산 등)에는 테스트를 추가한다.

## 1-1. 진행 원칙 (갭 표 검토 반영, 아래 스펙보다 우선)
- **Phase 0 = 결정 4개를 먼저 받는다**(코드 작업 없음): ① 콘텐츠 등급과 처치 표현(Minimal 유지 / Mild 활용: 랙돌→분해·크롬 부품 이탈·데이터 출혈 / Moderate) ② UI 디자인 토큰 3안 중 선택 ③ 오디오 소스 ④ RAM→체력 대납 기능 이름. 디자인 토큰과 오디오를 뒤로 미루지 않는다. 앞 Phase에서 만드는 UI·소리를 다시 만들게 되기 때문이다.
- **이름 충돌 금지**: 기존 `Overclock*`는 시간 감속 기능이다. RAM 부족분을 체력으로 내는 사이버덱 기능은 다른 이름(예: 생체 연산 `BioCompute`)을 쓴다. 기존 프리셋 이름(`hurt` 등)은 바꾸지 않고 스펙 이름과 매핑만 한다.
- **새로 만들지 말고 키운다**: 기존 `ScreenFx`·`ScreenFxRules`·`HitFeedback`·`FovController`·`OverclockRules`를 확장한다. `TimeScale`은 새 공용 모듈로 만들고 `OverclockRules`는 그걸 호출하는 래퍼로 남겨 기존 테스트를 유지한다.
- **수직 슬라이스**: Phase 1은 "기반 최소 + 크로노 완전체(4단계×4채널)"까지 하고 멈춘다. 내가 체감을 확인한 뒤 같은 파이프라인으로 나머지를 넓힌다. HighlightPool은 스캐너 직전(Phase 3)에 만든다.
- **새 UI는 전부 `UiTheme` 모듈**(색·폰트·사선 패널·글리치 등장 함수)로 만든다. 둥근 키즈 패널은 단계적으로 교체한다.
- **소리는 SFX 레지스트리(키→에셋 ID)로만 호출**한다. 에셋이 없으면 내장음으로 임시 매핑한다. 그러면 Phase 2의 4채널을 Phase 7 전에 끝낼 수 있다.
- **직접 검증**: 구현한 항목은 네가 Studio에서 직접 재현해 확인하고 증거(스크린샷, 출력 로그, 측정값)를 보고에 붙인다. 이를 쉽게 하려고 **개발용 검증 훅**(`RunService:IsStudio()`에서만 켜짐)을 만든다: 프리셋 재생(강도·동시 재생), 능력 강제 발동, 상황 재현(체력 낮음, 적 해킹 시작, 버블 안 NPC 공중 상태 등), 타이밍 측정 로그(발동~효과 ms). UI 패널도 같이 붙여 나도 눌러 볼 수 있게 한다.
- 모든 항목에 **완료 기준**(시간 ms, 채널, 수치)을 적고, 보고할 때 기준 충족 여부를 표로 보인다.

## 2. 공용 기반 (Phase 1 — 모든 것의 토대)

### 2-1. ScreenFX (클라이언트, 화면 효과 엔진)
- 효과를 "프리셋 + 강도(0~1) + 지속시간 + 페이드 인/아웃"으로 정의한다. 동시에 여러 개가 켜지면 **가중 합산**한다(색보정은 강도 가중 평균, 비네팅·글리치는 최대값).
- 레이어: ColorCorrectionEffect(전용 1개), BloomEffect, BlurEffect, DepthOfFieldEffect, 전면 ScreenGui(IgnoreGuiInset=true, DisplayOrder 최상단)에 다음 레이어:
  - 비네팅(가장자리 4개 Frame + UIGradient 투명도, 색 바꿀 수 있음)
  - 색수차 띠(화면 좌우·상하 가장자리에 빨강/시안 반투명 띠, 서로 반대 방향으로 2~6px 흔들림)
  - 스캔라인(가로 줄무늬, 천천히 스크롤)
  - 글리치 슬라이스 풀(가로 Frame 8~20개, 높이 2~40px, X 오프셋, 색 검정/시안/마젠타/흰색, 30~60ms마다 다시 섞음)
  - 필름 그레인(노이즈를 0.05초마다 오프셋)
  - 전면 플래시(흰색/색상)
- 카메라: 스프링 기반 Shake(위치 X, 회전 O), Punch(롤·피치 짧은 충격), FOV 펀치. 기존 카메라 코드와 충돌하지 않도록 "오프셋을 마지막에 더하는" 방식으로 붙인다.
- 소리: SoundGroup "World"에 EqualizerSoundEffect + ReverbSoundEffect. 프리셋으로 먹먹함(고음 감쇠)을 제어한다.
- 그래픽 품질 설정과 연동한다: 저사양/모바일에서는 그레인·스캔라인·글리치 슬라이스 수를 줄인다.
- 필수 프리셋(전부 만든다): hit(피격), lowHealth(체력 30% 이하 지속, 채도↓·심장 박동), electric(전기/EMP: 강한 글리치+HUD 깜빡임), burn(주황 가장자리 일렁임), toxic(녹색 비네팅+약한 흐림), flash(섬광: 흰색 → 3초 복귀 + 이명), blind(시각 재부팅: 노이즈 화면 + "OPTICS REBOOT" 류 자체 문구 + 부팅 복귀), boot(사이버웨어 설치 후 부팅: 검정→격자 보정→로그 스크롤→흐림 해제 2.5초), chrono(§3-2), reflex, scanner(§4-1), camo, heal, revive(체력 0 자동 부활: 암전→심장 2번→흰 플래시+재가동 글리치), rage(붉은 톤+글리치), overclock(기존 시간 감속 층 유지), bioCompute(RAM→체력 대납: 청색 글리치 톤), menuOpen/menuClose(모든 패널의 열기/닫기에 연결까지)(글리치 트랜지션+DOF), death(기울며 쓰러짐+채도 0+신호 끊김 노이즈).

### 2-2. TimeScale (공용 모듈, 시간 배율 시스템)
- 로블록스에는 전역 시간 감속이 없고 멀티플레이어라서, "엔티티별 시간 배율"로 구현한다.
- API 예: `TimeScale.get(entity)`, `TimeScale.pushBubble(owner, radius, scale, duration)`, `TimeScale.dt(entity, dt)`.
- 서버: 버블 반경 안의 NPC·투사체·장치에 배율을 적용한다. 버블이 겹치면 가장 작은 배율을 쓴다. 버블 주인 자신은 1.0이다.
- 적용 대상: NPC AI 틱, AnimationTrack:AdjustSpeed, Humanoid.WalkSpeed, 자체 투사체 시뮬레이션, ParticleEmitter.TimeScale, 문·엘리베이터 Tween, 공중의 물리체(속도 감쇠 + 중력 상쇄 VectorForce), 주변 사운드 PlaybackSpeed.
- **두 층으로 나눈다**: 서버 버블(NPC AI·애니·걷기·적 탄 — 근처 협동 플레이어도 같이 느린 적을 본다, PvP 제외) / 클라이언트 로컬 배율(비·비행차·파티클·주변 소리·화면 효과 — 사용자 본인 화면에서만).
- Humanoid 중력은 배율이 안 먹는다: 공중 NPC는 버블 진입 시 속도×s, 위쪽 `VectorForce = 질량×g×(1−s²)`, 버블을 나가면 복구.
- 다른 플레이어 시점: 버블 주인이 매우 빠르게 보이고 반투명 네온 잔상이 0.25초 동안 페이드한다. 잔상은 서버에서 만들지 않는다. 각 관찰자 클라이언트가 고스트 6개(low 3개)를 링버퍼로 재사용한다.
- 기존 크로노 OS가 이미 시간 관련 로직을 가지고 있으면 이 모듈로 옮기고 테스트를 유지한다.

### 2-3. HighlightPool
- Highlight는 동시에 31개까지만 렌더된다. 요청을 우선순위(스캐너 대상 > 해킹 중 > 적 > 장치 > 전리품)와 거리로 정렬해 상위만 켠다.

## 3. 사이버웨어 발동 연출 (Phase 2 — 최우선 체감 작업)
모든 능력은 **발동 / 지속 / 종료 / 쿨다운** 4단계를 갖고, 각 단계마다 "화면 + 소리 + 카메라 + HUD" 4채널 피드백이 있어야 한다. 하나라도 비면 채운다. 진화 단계(1→2→3A/3B)가 올라갈수록 같은 연출이 더 화려해지게(색 강도·파티클 수·사운드 레이어) 단계별 파라미터를 둔다.

### 3-1. 공통 HUD
- 좌하단 사이버웨어 슬롯 아이콘 + 원형 쿨다운. 준비되면 짧게 빛나며 "삑".
- 지속형 능력은 조준선 주변에 얇은 원형 잔여 시간 게이지.

### 3-2. 크로노(OS, 시간 가속) — 레퍼런스의 대표 능력
- 발동 0.25초: 상승 "슉"음 + 저음 쿵, FOV +10 → +4로 정착, ColorCorrection Tint 자체 색(연청록 계열, 예: RGB 150,255,230 — 다른 색을 써도 됨), Saturation −0.35, Contrast +0.2, 1프레임 흰 플래시(투명도 0.6), 색수차 띠 0.3초, 카메라 롤 펀치 1.5°.
- 지속: TimeScale 버블(세상 0.1~0.3배, 진화 단계별), 비네팅 0.5, 약한 스캔라인, Blur 2, 심장 박동 루프 60~70bpm, World 사운드 먹먹하게 + PlaybackSpeed 0.6, 총알·탄피·피 파티클도 느려짐.
- 종료 0.15초: 역Tween + "팝"음 + 색수차 0.15초.
- 처치 시 지속시간 연장 / 조기 해제 시 쿨다운 일부 환급은 진화 분기 옵션으로 둔다.

### 3-3. 리플렉스(신경계, 반응형 감속)
- 조건형 짧은 감속(1.5~2초): ① 대시·슬라이드 중 조준 ② 체력 25% 이하 진입 ③ 적에게 발각되는 순간. 각 조건은 진화 분기에 매핑한다.
- 크로노보다 약한 색 변화 + "휙"음. 체력 조건일 때는 붉은 톤 + 심장 박동.

### 3-4. 레이지(OS, 광폭화)
- 발동: 붉은 톤, 화면 가장자리 맥동, 저음 포효성 신스, 근접 피해·방어력 증가.
- 공중에서 앉기 키 → 급강하 착지 충격파(바닥 균열 데칼, 원형 충격파 링, 큰 카메라 흔들림, 주변 넉백). 다리 "슬램"과 겹치면 하나의 공용 충격파 모듈을 쓴다.

### 3-5. 사이버덱(OS) — 생체 연산(이름은 Phase 0에서 확정, 기존 Overclock과 다른 이름)
- RAM이 모자라면 체력으로 낸다(비율은 밸런스 상수, 체력 하한 있음, Lune 테스트). 발동 중 bioCompute 프리셋(청색 글리치) + 업로드 속도 증가.
- 드론·확산 분기는 기존 구현을 유지하고 연출만 4채널로 채운다.

### 3-6. 팔
- **꺼내기 애니메이션이 핵심이다.** GunShapes처럼 코드로 부품을 조립하고, 부품 단위로 Tween한다.
  - 블레이드: 전완 장갑판 2~3장이 회전해 열림(0.15초) → 칼날이 접힌 상태에서 회전하며 펴지고 길어짐(0.2초) → "철컥-스릉" 사운드. 빠른 연속 베기, 부위 절단. **충전 도약**: 누르고 있다가 놓으면 대상에게 포물선 도약 → 내려찍기 + 충격파.
  - 파워암: 손등 장갑이 맞물리며 발광. 충전 펀치 = 원형 충격파로 주변 넘어뜨림, 강한 화면 흔들림.
  - 나노와이어: 손목에서 빛나는 와이어(Beam, 휘두를 때 CurveSize 변화). 충전 = 넓은 수평 베기. 와이어 적중 시 지정한 해킹 1개를 RAM 없이 업로드하는 분기.
  - 런처: 손목 발사관이 열림. 포물선 궤적 미리보기(Beam). 충전 = 5발 분산.
- 칼 계열은 막기 상태에서 총알 튕겨내기(스태미나 소모, 불꽃). 크로노 중에는 자동으로 쏜 적에게 반사.

### 3-7. 다리
- 기존 비행·슬램·벽타기·그래플·슈퍼점프는 유지하고, 각 동작에 4채널 피드백(발밑 압축 공기 링 파티클, 서보음, FOV 펀치, 착지 쿵)을 채운다.
- 슈퍼점프: 점프 키를 누르고 있으면 화면 하단 충전 게이지가 찬다.

### 3-8. 위장 / 바이오 펌프
- 위장: 1인칭 뷰모델을 Glass 재질 + 투명도 0.7 + 약한 Reflectance로 바꾼다. 다른 플레이어에게는 Glass·투명도 0.9·ForceField 재질 일렁임. 화면 가장자리 굴절 일렁임(camo 프리셋). 공격하면 해제되며 "치직" 해제 연출.
- 바이오 펌프: heal 프리셋(녹색 펄스 + 심장 펌프음). 자동 부활 분기가 있다면 revive 프리셋. 나눠주기(아군 회복)는 대상 머리 위 녹색 펄스 + 연결 Beam.

### 3-9. 시술소(사이버웨어 교체 장소) 연출
- 의자에 앉으면 카메라 고정 + DepthOfField + 화면 어둡게.
- 교체 UI: ViewportFrame에 플레이어 캐릭터 복제(천천히 회전) + 부위별 슬롯 + 진화 단계·적응도 + 비교 수치(증가 초록/감소 빨강).
- 교체 완료 후 boot 프리셋(부팅 연출).
- 부위 슬롯 확장 준비: 전두엽·골격·손·눈·얼굴 슬롯을 데이터 구조에만 추가해 두고(빈 슬롯 UI 표시), 실제 아이템은 내 승인 후 만든다.

## 4. 넷러닝 체감 (Phase 3)

### 4-1. 스캐너 모드 (신규, 별도 키: PC Tab 홀드 / 패드·모바일 전용 버튼)
- 기존 E 탭(즉시 해킹)·E 홀드(휠)는 유지한다.
- 켜면: scanner 프리셋(자체 단색 톤 + 비네팅 + 스캔라인), 전투 중이면 플레이어 주변 TimeScale 0.3 버블, HighlightPool로 적(빨강)·해킹 가능한 장치(노랑)·전리품(등급색) 하이라이트.
- 화면 중앙 대상 정보 패널: 이름, 소속, 위협도, 약점/저항 속성, 상태. 처음 보는 대상은 스캔 진행 바(0.6초)가 찬다.
- 화면 오른쪽 해킹 목록: 이름 / RAM 비용 / 업로드 시간 / 쿨다운. 고르면 RAM 바에 쓸 칸이 깜빡인다.
- 마우스 휠로 광학 줌 단계(1x/2x/4x).
- 같은 네트워크 ID끼리 시안 Beam 연결선.

### 4-2. 업로드 연출 보강
- 내 손 → 대상으로 시안 데이터 Beam(텍스처 스크롤), 대상 머리 위 해킹 이름 + 진행 바, 완료 순간 대상 위치에 글리치 파티클.

### 4-3. 적 넷러너 → 나 해킹 (공용 구조만)
- 서버 API: `HackPlayer(attacker, player, hackId, uploadTime)`. 클라이언트는 화면 상단 중앙 경고 바(해킹 이름 + %) + 진행될수록 가장자리 노이즈 증가.
- 취소 조건: 시야 차단 / 공격자 사망 / 방어 사이버웨어 1회 차단. 스캐너를 켜면 공격자를 역추적해 강조.
- 완료 효과: burn / blind / 사이버웨어 봉인 / 무기 걸림 프리셋 연결.
- 테스트용 더미 넷러너 1개로만 검증한다(새 적 종류 추가 아님).

### 4-4. 장치 해킹 (허브에 배치)
- 감시 카메라 탈취: 내 시점이 카메라로 바뀌고 녹화 UI(REC·시간·노이즈) 오버레이, 좌우 회전, 다른 카메라로 점프.
- 자판기·TV 주의 분산, 가로등·간판 과부하(불꽃), 단말기 폭발.

### 4-5. 접속 단자 침투 미니게임
- 행·열을 번갈아 고르며 목표 순서를 버퍼에 채우는 퍼즐. 기호·색·보상 이름은 자체 디자인(예: 자체 글리프). 격자 5×5~7×7, 버퍼 4~8, 목표 1~3개, 첫 선택부터 제한 시간. 보상: RAM 비용 감소 버프, 돈, 주변 카메라 끄기.
- 판정 로직은 순수 모듈로 분리하고 lune 테스트를 붙인다.

## 5. HUD 전면 개편 (Phase 4)
자체 디자인 언어: 사선으로 깎은 패널, 얇은 외곽선, 모노스페이스 숫자, 작은 장식 텍스트(좌표·바코드풍). 기본색/해킹색/경고색 3색 체계를 정해서 나에게 먼저 보여 준다.
- 좌상단: 체력 바(지연 감소 잔상 바) + 레벨, 상태 이상 아이콘(원형 남은 시간), RAM 셀 바.
- 스태미나: 소모할 때만 표시.
- 좌하단: 사이버웨어 슬롯·쿨다운, 회복·수류탄 충전.
- 우하단: 탄약(현재/예비 크게, 부족하면 색 변화·깜빡임), 무기 이름, 슬롯.
- 우상단: 원형 미니맵(맵 이미지 + 회전 아이콘 방식) + 목표 텍스트·거리. 전투 중 테두리 색 변화.
- 중앙: 무기별 동적 조준선(이동·연사·조준에 따라 확산), 히트 마커(일반/헤드샷/처치 모양·색·소리 구분).
- 데미지 숫자: ScreenGui 풀 50개 + WorldToViewportPoint. 치명타 크게, 속성별 색(물리/열/전기/화학).
- 피격 방향 붉은 호, 화면 밖 적 방향 화살표.
- 적 머리 위: 체력 바, 위협도 아이콘, 탐지 게이지(흰→노랑→빨강).
- 모든 HUD 요소는 등장할 때 글리치(0.12초 X 흔들림 + 빨강/시안 어긋난 복제 텍스트)를 쓴다.
- 레벨 업·적응도 만렙·진화 가능 알림: 화면 상단 큰 글자 + 효과음 + 글리치.
- 모바일: 기존 모바일 조작과 겹치지 않게 배치를 따로 잡는다.

## 6. 기본 이동·총기 손맛 (Phase 5)
- 대시(방향 2번 탭/전용 키, 0.15초, 스태미나), 슬라이드(달리다 앉기, 카메라 낮추고 2° 기울임, 슬라이드 중 사격), 넘어가기·매달려 오르기(앞·위 레이캐스트로 턱 판정), 착지 흔들림(필수, 높이별 카메라 쿵)·낙하 피해(키즈면 끔), 스태미나(사격·근접·대시 소모, 달리기는 무료). 이단 점프·공중 대시가 다리 진화에 없으면 기본 다리 1단계에 넣을지 나에게 묻는다.
- 달리기 자세: 총을 비스듬히 내림 + FOV +5.
- 총: 총마다 반동 패턴 테이블(카메라 스프링 + 뷰모델 스프링 2단, 연사 누적), 총구 화염(PointLight 1프레임 + 파티클), 탄피 배출, 예광탄, 재질별 탄착 효과 테이블, 빈 탄창 재장전 애니메이션 분리, 살펴보기 애니메이션.
- 무기 기술 계열 3종을 12종 총에 배정: 도탄형(반사 레이 1~3회, 보조 사이버웨어 시 궤적 미리보기), 충전 관통형(충전 게이지, 두께·재질별 감쇠, 충전 시 벽 뒤 적 하이라이트), 유도형(화면 중앙 원뿔 락온, 락온 마커, 유도 투사체).
- 처치(Phase 0-① 결정을 따른다): Mild 활용이면 랙돌(Motor6D→BallSocket) 0.6~1.0초 후 기존 분해(DissolveService), 산탄·칼날·파워암은 "크롬 부품 이탈"(사이버 팔다리가 스파크·네온 냉각액과 함께 떨어져 나가고 바로 글리치 조각으로 분해), 피 대신 시안/마젠타 "데이터 출혈" 입자. 사실적 피·시체 방치는 넣지 않는다.
- 은신·잡기: 뒤에서 잡기 → 목 뒤 포트에 해킹 잭을 꽂는 신경 차단 제압(비살상) / 처치, 인간 방패(잡은 적을 앞에 두고 권총 사격, 마지막에 던지기), 운반.
- 투척: 칼·도끼 투척과 회수, 수류탄 던지기 전 포물선 궤적 미리보기.
- 스마트 무기: 적 몸 락온 마커 + 조준선 주변 락온 원 UI가 있는지 확인하고 없으면 추가.
- 전리품: 등급색(흰·초록·파랑·보라·주황) 외곽선과 짧은 빛 기둥.
- 근접 공용: 약/강(충전)/막기/막기 직후 반격, 피니셔(적 체력 낮을 때 프롬프트 → 1인칭 카메라 시퀀스 0.8~1.5초, 그동안 무적).

## 7. 허브 도시 분위기 패스 (Phase 6 — 맵 우선순위와 직결)
- Lighting: Technology=Future, 밤 ClockTime, 낮은 Ambient, Atmosphere(Density 0.35~0.45, Haze 2~3, 보라/청록 색), Bloom 강하게.
- 수직성: 허브 외곽에 초고층 실루엣 + 창문 Neon 점(기존 확장), 고가도로·육교 1~2개, 계단·지하 입구.
- 네온 간판: Neon Part + SurfaceGui(자체 상호, 여러 언어풍 자체 문구), 층층이 겹치게 배치, 일부 글자 고장 깜빡임 스크립트.
- 홀로그램 광고: 반투명 Part + SurfaceGui 프레임 애니메이션 + 가장자리 스캔라인, 공중에 떠서 천천히 회전/흔들림. 내용은 전부 자체 브랜드.
- 젖은 바닥: 바닥 SmoothPlastic 진한 색 + Reflectance 0.1~0.2, 간판 아래 바닥에 간판색 세로 반사 줄기(위→아래 투명도 그라디언트).
- 대기: 비 파티클(카메라 추적 박스) + 바닥 튀김, 하수구 증기, 안개 파티클, 빛줄기 Beam.
- 거리 소품: 자판기, 노점, 쓰레기, 그래피티(자체 제작), 철망, 실외기, 전선 다발, 스크린, 단말기. 해킹 가능한 장치는 Attribute로 표시.
- 구역 색 정체성: 허브를 2~3개 구역으로 나누고 진입 시 Atmosphere/ColorCorrection Tween 교체.
- 클라이언트 전용 군중: 단순 리그 NPC, 인도 경로 순환, 거리 LOD, 총소리 이벤트에 웅크리고 도망. 서버 복제하지 않는다.
- 교통·하늘 비행 차량: 클라이언트 전용 스플라인 이동.
- 앰비언트 사운드: 위치별 3D 사운드(광고 방송, 군중, 비, 사이렌 멀리), 구역별 Reverb.
- 성능: 화면 효과 ≤1ms/프레임, StreamingEnabled 확인, 모바일 품질 프리셋에서 군중 수·파티클·광원 감소. 파츠 수 보고.
- 모험 맵은 구상 단계라 만들지 않는다. 대신 허브에서 쓴 소품·간판·광고·군중 모듈을 재사용 가능한 모듈/프리팹으로 만든다.

## 8. 사운드 레이어 (Phase 7)
- 동적 음악: 평상시/경계/전투 3트랙 동시 재생 + 볼륨 크로스페이드(전투 상태 신호 연결).
- 능력 3단 사운드(발동/루프/종료) 전부 연결 확인표 작성.
- UI 사운드: 삑, 글리치 지지직, 히트 마커, 레벨 업.
- 오디오는 라이선스 확인된 것만. 에셋 ID 목록을 `docs/audio-assets.md`로 남긴다. 적당한 게 없으면 자리만 만들고 나에게 업로드를 요청한다.

## 9. 진행 방식
- Phase 순서: 0(결정 4개) → 1(기반 최소 + UiTheme + SFX 레지스트리 + 크로노 완전체, 멈추고 확인) → 2(프리셋 19종 + 사이버웨어 전체 4채널) → 3(HighlightPool + 넷러닝) → 4(기존 HUD를 UiTheme으로 교체) → 5(이동·총·근접·은신·처치 표현) → 6(허브 분위기 + 성능) → 7(음악·앰비언트 완성). 내가 바꾸라고 하면 바꾼다.
- 각 Phase가 끝날 때 보고: ① 만든/바꾼 파일 ② 테스트 결과(통과 수) ③ **네가 Studio에서 직접 확인한 결과**(항목별 통과/실패 + 스크린샷·로그·측정값)와, 직접 확인할 수 없어 내가 봐야 할 항목(손맛, 모바일 실기기, 협동) ④ 레퍼런스 대비 남은 차이 ⑤ 다음 Phase 계획. 그리고 멈추고 기다린다.
- 확실하지 않은 디자인 결정(색 체계, 키 배치, 밸런스 수치, 새 슬롯 아이템)은 임의로 정하지 말고 선택지 2~3개를 제시해 묻는다.
- 성능 예산: 화면 효과 전체가 클라이언트 프레임당 1ms 이하가 되도록 풀링하고, Heartbeat 연결은 효과가 꺼지면 해제한다.
