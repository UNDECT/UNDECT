## 역할과 목표
너는 cyber-rpg(로블록스 1인칭 사이버펑크 게임)의 **테크니컬 아티스트 겸 환경 아티스트**다.
이번 작업은 **그래픽만** 한다. 목표는 첨부 2번 레퍼런스처럼 "AAA 사이버펑크 도시를 걷는 체감"을 허브 도시에서 내는 것이다.
레퍼런스의 **구도·스케일·밀도·빛·색 원리**는 최대한 똑같이 가져온다. 하지만 **간판 이름·로고·브랜드·특정 장소·캐릭터는 전부 자체 제작**한다. 다른 게임의 고유명사(경찰 조직명, 기업명, 도시명, 교통 브랜드 등)는 절대 쓰지 않는다.

## 0. 절대 규칙
- 답은 항상 한국어로 한다.
- Studio에 열린 `cyber-3v3.rbxl`은 절대 저장하지 않는다. `rojo build -o cyber-rpg.rbxl`은 실행하지 않는다. computer-use는 쓰지 않는다.
- Studio 확인은 네가 직접 한다(연결된 Studio 연동 도구로 실행, 플레이 테스트, 스크린샷, 로그). 손맛과 모바일 실기기만 나에게 묻는다.
- 기능 브랜치에서만 커밋한다(예: `graphics-pass-1`). 메시지 끝에 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`를 붙인다. main 머지·원격 push는 하지 않는다.
- 단계마다 `~/.rokit/bin/lune.exe run tests/run.luau`가 전부 통과해야 한다.
- 맵은 Rojo 프로젝트 구조를 따른다. 코드로 생성하는 부분(BuildKit, WorldBuilder 등)은 코드로, 에셋으로 넣는 부분은 **어디에 어떻게 저장해 Rojo와 동기화되는지 먼저 확인하고** 방식을 정해 나에게 알린다. 플레이 중에는 동기화되지 않는다는 점에 주의한다.

## 1. 에셋 규칙 (직접 찾아서 써도 된다 — 조건 있음)
**네가 에셋을 직접 찾아 넣어도 된다.** 다만 아래 조건을 전부 지킨다.

허용
1. 로블록스 내장 재질(Concrete, Asphalt, Metal, Glass, Foil, DiamondPlate, CorrodedMetal, Pavement, Brick 등)과 `MaterialService` MaterialVariant
2. 크리에이터 스토어(Creator Store) 에셋: 메시·모델·텍스처·데칼·스카이박스·오디오. 연결된 Studio 도구의 스토어 검색/삽입 기능(예: insert_model류)이나 툴박스 검색을 쓴다. **로블록스 공식 계정 제작물과 평가가 좋은 제작자 것을 우선**한다.
3. 코드로 만드는 것(Part, MeshPart, Beam, ParticleEmitter, SurfaceGui, EditableImage/EditableMesh)
4. 내가 업로드해 주는 에셋. 이미지 업로드가 필요하면 Open Cloud 업로드 방식을 제안하고, API 키는 내가 직접 환경 변수로 넣는다(저장소에 키를 남기지 않는다).
5. **CC0 사진 텍스처·모델**(Poly Haven, ambientCG 등 상업적 무료 사용 가능). 내려받아 로블록스 규격으로 줄이고 Open Cloud로 업로드한다. 출처를 기록한다.
6. **네가 Blender로 만든 모델**: `blender --background --python`으로 헤드리스 실행해 모듈 건물·소품·차량·반전 메시를 만들고 AO를 굽고 FBX로 내보낸다.

금지와 검사
- **스크립트 금지**: 삽입한 모델 안의 `Script`/`LocalScript`/`ModuleScript`는 전부 삭제한다. `require(숫자)`, `loadstring`, `getfenv`, 숨은 이름의 스크립트가 있었으면 그 에셋은 **통째로 버리고** 기록한다.
- **다른 게임에서 뜯어 온 에셋 금지**: 이름·설명·텍스처에 다른 게임 이름이나 그 게임의 고유명사·로고가 있으면 쓰지 않는다. 유명 게임과 똑같이 생긴 차·간판·캐릭터도 쓰지 않는다.
- **스타일 통일**: 이번 목표는 **세미 리얼 PBR**이다. 카툰·로우폴리 장난감 스타일 에셋은 섞지 않는다.
- **성능 검사**: 메시 삼각형 수, 텍스처 해상도, 파츠 수를 확인한다. 같은 에셋은 복제로 재사용한다.
- 모든 에셋을 `docs/asset-ledger.md`에 기록한다: 에셋 ID / 이름 / 제작자 / 용도 / 배치 위치 / 삭제한 스크립트 수 / 날짜 / 라이선스 메모.

검색 키워드 예시(영어로 검색): modular skyscraper, sci-fi building, apartment facade, storefront, fire escape, AC unit, rooftop water tank, antenna, pipes, overhead cables, street lamp, traffic light, crosswalk, bus stop, vending machine, food stall, kiosk, trash bags, barrier, bollard, planter, palm tree, sedan, taxi, van, truck, monorail track, elevated highway, billboard frame, neon sign, hologram, concrete texture, asphalt texture, wet road, skybox hazy city, clouds.

## 2. 첨부 사진 설명

### 1번 — 지금 화면
- 전체가 **청록 회색 안개 한 가지 색**이다. 하늘이 보이지 않고 원근감이 없다.
- 건물은 6~10층짜리 상자 모양이고, 창문은 색칠한 사각형이다. 건물 사이 높이 차이와 겹침이 없다.
- 길이 넓고 비어 있다. 사람·차·소품이 거의 없다.
- 가로등과 간판 일부는 **순수 검정 실루엣**이다(주변광이 너무 낮다).
- 네온 간판은 작고 드물다(분홍 한글 간판 하나가 눈에 띄는 정도).
- 가로등 빛 원뿔은 있지만 화면에 강한 광원과 대비가 없다.
- 총 뷰모델이 거의 검은 덩어리로 보인다.

### 2번 — 목표 레퍼런스(낮, 늦은 오후)
- **강한 햇빛**: 따뜻한 주황빛 직사광, 또렷한 그림자, 그늘은 푸른 톤. 따뜻함과 차가움이 강하게 대비된다.
- **하늘이 보인다**: 밝은 청록 하늘. 먼 건물은 대기 원근으로 연하게 날아간다.
- **수직 스케일**: 화면 위로 끝이 안 보이는 초고층 건물. 저층·중층·고층이 겹겹이 쌓인다.
- **도로 위를 가로지르는 고가 구조물**: 모노레일 선로와 교각, 고가 도로, 육교. 이게 실루엣의 핵심이다.
- **간판 밀도**: 세로 간판이 층층이 쌓이고, 거대한 광고판과 스크린이 있다. 낮인데도 광고가 빛난다. 노랑·마젠타·시안·빨강.
- **거리층 디테일**: 횡단보도, 신호등, 가판대, 노점, 차양, 화분, 야자수, 펜스, 배리어.
- **생동감**: 보행자 수십 명, 택시와 승용차, 주차된 차.
- **재질 다양성**: 콘크리트, 유리 커튼월, 금속 패널, 타일 보도.

## 3. 진단 — 왜 지금 사이버펑크로 안 보이나 (우선순위 순)
1. **대기(Atmosphere)가 너무 짙고 한 가지 색**이다 → 모든 것이 같은 색으로 덮인다. 대비·하늘·원근이 사라진다.
2. **주광(해/달)과 주변광 설계가 없다** → 형태가 안 보이고 검정 실루엣이 생긴다.
3. **스케일이 작다** → 건물이 낮아서 "메가시티"가 아니라 "작은 마을"로 보인다.
4. **레이어가 없다** → 전경·중경·원경과 고가 구조물이 겹쳐야 깊이가 생긴다.
5. **간판·광고 밀도가 10분의 1 수준**이다.
6. **거리층이 비어 있다** → 사람·차·소품이 없다.
7. **재질이 단조롭다** → 평평한 단색 면이 대부분이다.
8. **색 팔레트가 단색**이다 → 따뜻한 빛과 차가운 그림자, 원색 네온 포인트가 없다.

## 4. 진행 단계

각 단계: 작업 → **고정 촬영 지점 스크린샷으로 직접 비교** → 체크리스트 수치 보고 → 다음 단계. G0과 G1이 끝나면 멈추고 내 확인을 받는다. 그 뒤로는 단계마다 보고만 하고 계속 진행하되, 내가 멈추라고 하면 멈춘다.

### G0. 기준 고정 + 에셋 조사 (코드 변경 최소)
- 허브에 **고정 촬영 지점 5곳**을 정한다(Attribute나 설정 모듈에 카메라 CFrame과 FOV 저장). 그중 1곳은 레퍼런스 구도와 비슷하게 잡는다: 교차로 모서리, 눈높이, 도로를 대각선으로 바라보며 위쪽 30%에 하늘.
- 5곳의 **현재 스크린샷**을 찍어 `docs/graphics/before/`에 저장한다.
- 개발용 도구(`RunService:IsStudio()`에서만): 촬영 지점 순회, 낮/밤 프리셋 전환, 화면 안 통계(파츠 수, 간판 수, NPC 수, 광원 수) 표시.
- **에셋 조사 보고서** `docs/graphics/asset-survey.md`: 분류별 후보(건물 모듈, 거리 소품, 차량, 야자수, 고가 구조물, 스카이박스, 텍스처)를 각 3~5개씩 고른다. ID·제작자·삼각형 수·스타일 적합도·스크립트 유무를 적고, 추천안을 표시한다.
- 3번 진단에 동의하는지, 놓친 원인이 있는지 보고한다.

- **검정 실루엣 제거**: OutdoorAmbient를 올리고, 순수 검정에 가까운 Color(RGB 합 < 60)를 쓰는 파츠를 찾아 보고한 뒤 어두운 회색·금속으로 바꾼다.
- 구역 색(`ScreenFxRules.districtGrade`)이 새 프리셋을 덮어쓰지 않는지 확인하고 강도를 다시 맞춘다.
- 낮 ↔ 밤 전환: 시간 흐름 또는 구역·이벤트로 바꿀 수 있게 하고, 전환은 Tween으로 30초에 걸쳐 한다.
- 완료 기준: 1번 촬영 지점에서 ① 하늘이 화면 위쪽 25% 이상 보인다 ② 햇빛 면과 그늘 면의 밝기 차이가 눈으로 분명하다 ③ 먼 건물일수록 연해진다(대기 원근) ④ 순수 검정 실루엣 0.

### G2. 스케일과 실루엣 — 레이어 5단
기준: 캐릭터 키 ≈ 5.5스터드 ≈ 1.8m이므로 1m ≈ 3스터드, 한 층 ≈ 11~13스터드다.

| 레이어 | 높이(스터드) | 내용 |
|---|---|---|
| L0 거리층 | 0~30 | 상점 전면, 차양, 간판, 소품, 사람 |
| L1 저층 상가 | 30~120 | 세로 간판, 발코니, 실외기, 비상계단, 광고판 |
| L2 고가 구조물 | 40~120 | **도로를 가로지르는** 모노레일 선로와 교각, 고가 도로, 육교, 공중 통로 |
| L3 중경 타워 | 120~350 | 커튼월 유리, 층마다 띠, 옥상 구조물 |
| L4 원경 메가타워 | 350~900 | 실루엣 + 창문 불빛 점, 대기에 묻혀 연함, 꼭대기 항공 경고등 |

- 허브 중심 도로는 6차선급으로 하고, 양쪽 보도는 15~20스터드로 한다.
- 각 촬영 지점에서 **고가 구조물이 최소 2개** 화면을 가로지르게 배치한다.
- 건물 윤곽은 상자가 아니게: 후퇴층(setback), 돌출부, 모서리 깎기, 옥상 장비(물탱크, 안테나, 헬기장, 광고 프레임).
- 원경 L4는 저폴리 실루엣으로 하고 `RenderFidelity`/스트리밍으로 비용을 낮춘다.

### G3. 파사드와 재질
- 건물을 **모듈 키트**로 만든다: 창 모듈(프레임+유리+실내 깊이감), 층 띠, 기둥, 발코니, 실외기, 비상계단, 배관, 환기구, 상점 전면 셔터.
- 창: 낮에는 Glass(Reflectance 0.2~0.35, 투명도 낮게)로 하늘을 비춘다. 밤에는 창 일부(30~50%)에 따뜻한/차가운 불빛을 켠다(SurfaceGui LightInfluence 0 + Brightness 1.5~3, 또는 작은 Neon). 무작위 패턴이지만 시드는 고정한다.
- 재질 배분: 콘크리트 40%, 유리 커튼월 25%, 금속 패널 20%, 타일·벽돌 15%. 단색 SmoothPlastic 면은 없앤다.
- 필요하면 MaterialVariant(PBR: Color/Normal/Roughness/Metalness)로 콘크리트 얼룩, 젖은 아스팔트, 녹슨 금속, 보도 타일을 만든다. 텍스처는 스토어에서 찾거나 업로드를 요청한다.
- 노화 표현: 물자국·그을음 데칼, 그래피티(자체 제작), 녹, 테이프.

### G4. 간판·광고·홀로그램 밀도
- ⚠️ (수정) 예전의 "화면당 간판 25개 이상" 기준은 폐기했다. 간판이 너무 많아져 분위기를 망쳤다. **`send-to-claude-code-c3-onward.md`의 계층 규칙과 면적 기준(번화가 ≤ 15%, 기업 구역 ≤ 5%, 영웅 광고 1~2개)**을 따른다.
- 자체 브랜드 20개 이상을 만든다(가상 음료, 사이버웨어 회사, 라멘집, 클럽, 보험사, 통신사 등). 한글·영어·일본어풍·숫자를 섞되, 실존 브랜드나 다른 게임 브랜드와 비슷하지 않게 한다. 브랜드 목록은 `docs/graphics/brands.md`에 둔다.
- 광고 그림: ① SurfaceGui로 직접 디자인(큰 타이포, 그라디언트, 도형, 제품 실루엣, 애니메이션) ② 라이선스가 확인된 데칼 ③ 내가 업로드한 이미지. 기본은 ①로 하고, 품질이 부족하면 ③을 요청한다.
- 낮에도 광고가 빛나 보이게: SurfaceGui `LightInfluence = 0`, `Brightness` 2~4, Bloom Threshold와 맞춘다.
- 네온 튜브 간판: Neon 재질 + 뒤판 + PointLight/SurfaceLight(광원 개수 예산 안에서). 일부 글자는 고장 깜빡임.
- 홀로그램: 반투명 파츠 + SurfaceGui + 스캔라인 + 천천히 회전·흔들림 + 아래쪽 투사기.

### G5. 거리층 디테일
- 바닥: 아스팔트(차선, 횡단보도 줄무늬, 맨홀, 균열 데칼), 보도 타일, 연석 높이 차이, 배수구.
- 소품(촬영 지점 화면마다 종류 15개 이상): 신호등, 가로등(디자인 2종), 버스 정류장, 자판기, 노점(차양+조명), 키오스크, 벤치, 화분, 야자수(중심가 구역), 쓰레기 봉투·통, 바리케이드, 볼라드, 소화전, 공중 케이블, 표지판, 광고 기둥, 실외기, 철망.
- 젖은 표현(밤·비 구역): 간판 아래 가짜 반사 줄기, 물웅덩이(Glass 재질 얇은 판 + 반사).
- 하수구 증기, 노점 연기, 빛줄기 Beam.

### G6. 생동감 (클라이언트 전용, 서버 복제 없음)
- 보행자: 촬영 지점 화면마다 20명 이상. 옷 색·체형·걷기 속도를 다양하게. 보도 경로를 따라 순환하고, 신호등에서 대기한다. 멀어지면 숨긴다(LOD).
- 차량: 도로를 주행하는 차 6대 이상 + 주차된 차. 택시는 자체 도색이다(다른 게임의 택시 디자인을 베끼지 않는다). 전조등·후미등은 Neon.
- 하늘: 기존 `SkyTraffic` 비행차를 고가 구조물 사이 높이로 끌어내리고 밀도를 높인다.
- 모노레일: 선로 위로 열차가 주기적으로 지나간다(소리는 사운드 단계에서).
- 낮/밤에 따라 군중 밀도와 옷 색 비율을 바꾼다.

### G7. 1인칭 뷰모델 그래픽
- 지금은 총이 검은 덩어리로 보인다. 재질을 금속(Metal/DiamondPlate)과 플라스틱으로 나누고 색 대비를 준다. 작은 Neon 포인트 라인(조준경, 탄창 표시)을 넣는다.
- 뷰모델 전용 보조 조명(약한 PointLight)으로 어두운 곳에서도 형태가 보이게 한다.
- 장갑·소매 재질도 패브릭/가죽 느낌으로 대비를 준다.

### G8. 성능과 품질 프리셋
- 기존 그래픽 품질 설정에 연결한다. low에서는 원경 창 불빛, 홀로그램 애니메이션, 군중 수, 광원 수, 파티클을 줄인다.
- 예산(시작값): 촬영 지점 화면 안 활성 광원 ≤ 40, 군중 ≤ 30(low 10), 데스크톱 60fps, 모바일 30fps 목표.
- StreamingEnabled를 확인하고, 허브 전체 파츠 수·메시 수·텍스처 메모리를 단계마다 보고한다.
- 반복 소품은 복제 재사용, 원경은 단순 메시.

## 5. 검증 방법 (단계마다)
1. 고정 촬영 지점 5곳 스크린샷(낮·밤 각각)을 찍어 `docs/graphics/<단계>/`에 저장한다.
2. 레퍼런스(2번)와 나란히 놓고 아래 표를 채운다. 화면 안 통계는 개발 도구로 센다.

| 기준 | 목표 | 측정값 |
|---|---|---|
| 하늘 비율(1번 지점) | ≥ 25% | |
| 가장 높은 건물이 화면 위로 잘림 | 예 | |
| 고가 구조물 가로지름 | ≥ 2 | |
| 간판·광고 화면 면적 / 영웅 광고 / 이유 없는 간판 | 구역 기준 안 / 1~2 / 0 | |
| 보행자 / 차량 | ≥ 20 / ≥ 6 | |
| 소품 종류 | ≥ 15 | |
| 순수 검정 실루엣 | 0 | |
| 따뜻한 빛과 차가운 그늘 대비 | 분명 | |
| 원색 포인트(노랑·마젠타·시안·빨강) | 4색 모두 보임 | |
| 밤: 바닥에 네온 반사 보임 | 예 | |
| 낮: 유리 빌딩에 하늘·도시 반사 | 예 | |
| 구석 그늘(AO)·반사광 물듦 | 보임 | |
| 렌즈 플레어(해를 볼 때) | 예 | |
| fps(데스크톱/모바일 에뮬) | ≥ 60 / ≥ 30 | |

3. 미달인 항목은 고치고 다시 찍는다. 같은 항목이 두 번 미달하면 원인과 대안을 보고한다.
4. 보고 형식: ① 바꾼 파일과 에셋 ② before/after 스크린샷 경로 ③ 위 표 ④ 테스트 결과 ⑤ 레퍼런스와 아직 다른 점 상위 5개 ⑥ 다음 단계.

## 6. 엔진 한계 돌파 — "안 되는 것"도 우회 기법으로 구현한다
`docs/reference/05-engine-limit-workarounds.md`를 먼저 읽는다. 아래는 필수 적용 항목이다. **"엔진이 지원 안 해서 못 함"으로 끝내지 않는다.** 아래 방법을 쓰고, 그래도 막히면 시도한 방법·결과 스크린샷·다음 대안을 보고한다.
작업 전에 Creator Hub 문서로 최신 기능(통합 조명, 발광 마스크, 텍스처 최대 해상도, SSR 출시 여부)을 확인하고 표로 보고한다.

### G9. 실시간 반사 → 거울 지오메트리
- `BuildKit`/`WorldBuilder`가 도시를 만들 때 **위아래가 뒤집힌 가벼운 복제본**(실루엣, 창 불빛, 간판, 광고만)을 클라이언트 전용으로 같이 만든다.
- 파츠 뒤집기: 위치 `(x, 2h−y, z)`, 회전 `M·R·M`(`M=diag(1,−1,1)`). MeshPart는 Blender에서 반전 메시를 만들어 쓴다.
- 복제본: CastShadow·CanCollide·CanQuery·CanTouch 모두 false, 카메라 반경 300스터드만 활성, 품질 low에서는 끈다.
- 바닥: **물웅덩이만 반사(기본)** + 비 구역은 도로 전체 반사 옵션. 반투명 0.35~0.55 + 물결 노멀 MaterialVariant. 지하 공간(지하철 입구)은 제외한다.
- 완료 기준: 밤 촬영 지점에서 간판·광고 네온이 바닥에 일렁이며 비친다. fps 하락 ≤ 15%.

### G10. 유리 반사 → 도시 큐브맵 스카이박스
- 도시 중심에서 6방향(90° FOV)을 렌더링해 스카이박스를 만든다(Blender 프록시 렌더 또는 Studio 캡처). 낮·밤 두 벌. 아래쪽 절반은 원경 스카이라인으로 쓰고, 실제 L4 원경과 이어지게 맞춘다.
- `EnvironmentSpecularScale = 1`, 유리 커튼월 Reflectance로 레퍼런스처럼 하늘과 도시가 비치게 한다.

### G11. 전역 조명 → 베이크 + 가짜 반사광
- 모듈 건물은 Blender에서 **AO + 약한 간접광**만 디노이즈해서 구워 ColorMap에 넣는다(직사광은 굽지 않는다).
- 햇빛을 받는 큰 면과 큰 광고판 앞에 **그림자 없는 넓은 저밝기 fill light**(낮=따뜻한 색, 밤=광고 색)를 둔다.
- 접촉 그림자 데칼(건물 밑동, 소품 밑).
- 광원 예산(화면 안 40개) 안에서 한다.

### G12. 사진 질감·발광·후처리
- CC0 PBR 텍스처로 MaterialVariant 세트(콘크리트 3, 아스팔트 2(마른/젖은), 금속 3, 타일 2, 페인트 벽 3)를 만든다.
- **발광 마스크**로 창 불빛 패턴(4종 이상 무작위), 간판 글자, 광고 화면을 텍스처 안에서 빛나게 한다(`EmissiveStrength`·`EmissiveTint`).
- 렌즈 플레어(해 방향 스프라이트 + 가림 레이캐스트), 볼류메트릭 빛줄기(Beam 겹침 + 먼지 파티클), 진짜 색수차와 모션 블러는 ViewportFrame 방식을 **능력 발동 같은 짧은 순간 + 저해상도 프록시**에만 쓴다.
- 보행자는 사실 비율 인간형 메시 + 레이어드 클로딩 + 애니메이션 5종 이상, 차량은 Blender 자체 디자인 3~5종(유리·크롬 PBR, 발광 전조등).
- 반사·조명 기능은 모듈로 분리해, 엔진에 SSR 같은 기능이 나오면 바꿔 끼울 수 있게 한다.

### 준비물 확인 (G0에서 먼저)
- Blender 설치 여부(`blender --version`), Open Cloud API 키 환경 변수, 업로드 대상 그룹/계정 ID, CC0 사이트 접속 가능 여부를 확인한다. 없으면 무엇이 필요한지 나에게 한 번에 요청한다.

## 7. 시작
G0부터 시작한다. 촬영 지점 5곳의 before 스크린샷, 에셋 조사 보고서, 진단 의견, **최신 엔진 기능 확인표, 준비물 확인 결과**를 먼저 보여 주고 멈춘다. 진행 순서는 G0 → G1 → G2 → G3(+G11 베이크, G12 텍스처) → G4(+발광 마스크) → G5 → G9·G10(반사) → G6 → G7 → G8이다.
